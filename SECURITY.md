# Security policy

## Supported versions

Security fixes are made only on the current `main` branch and the most recent public deployment. Historical commits, archived change evidence, forks, and unofficial builds are not supported releases.

## Reporting a vulnerability

Do not disclose a suspected vulnerability in a public issue, pull request, discussion, or log attachment.

Use GitHub's [private vulnerability reporting form](https://github.com/seedlands-game/seedlands-web-sandbox/security/advisories/new). Include the affected commit or deployment watermark, reproduction steps, expected impact, and the smallest safe proof needed to understand the issue. Remove credentials, personal data, and unrelated private logs.

The project will acknowledge a report through GitHub, investigate it, and coordinate disclosure there. Response times are best-effort while the project has a single maintainer. If private vulnerability reporting is temporarily unavailable, wait for that channel to be enabled rather than publishing exploit details.
