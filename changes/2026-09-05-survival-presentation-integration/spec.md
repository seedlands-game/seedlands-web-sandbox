# 生存交互、物品图示与音画整合

**状态：Delivered；父 Goal 授权自主本地 SDD。**

## 背景与目标

Change8 提供服务端生存规则与 GUI，但背包格子不能移动物品，食物没有真实 GUI 使用入口；短音频尚未订阅生存操作。补齐玩家无需调试命令即可整理、装备、吃东西、采集建造的交互，并保持统一表现。

## 范围与明确不做

- 背包两次点击移动整组、同类合并、异类交换；前八格是快捷栏，可从任意背包格使用食物，世界中右键选中食物可食用。
- 按指定槽位扣除使用、放置和丢出的物品，不能错误扣除另一格同类物品；服务端验证存活、索引、数量、栈上限，失败无副作用。
- 统一物品图示、键位/数量/名称、选中与移动状态；添加食用与快捷栏装备的可见说明。
- 采集成功/放置成功/合成/拾取/食用/攻击/伤害的语义短音及清晰反馈，预算与会话沿用 Audio change。成功音必须来源于成功结果或可验证的服务端状态变化。
- 接入高级光影提供的灯笼物品、配方与掉落规则，让灯笼可自然制作和保存，不通过 debug 才能获得。
- 不做复杂拖拽、批量分装、装备耐久、网络交易或新经济系统；不改基础地形生成器。

## 关键决策

1. Inventory 的移动/指定格消耗是纯逻辑原子操作；GameServer façade 负责玩家存活、revision 与持久化。UI 不直接改 inventory snapshot。
2. 先选有物品的来源格，再选目标格；同格取消，满栈目标拒绝，异类交换。提供当前选取名称与操作提示，关闭背包清空临时选取。
3. 世界右键优先尝试选中食品语义，食品即使饥饿已满也不会被解释为放方块；失败只给明确反馈。
4. BrowserGameplay 发出 typed presentation event；音频只消费成功语义，伤害由前后权威生命状态识别。音频不得反向修改世界。
5. 物品图示用原有授权体素 atlas 与原创几何 SVG，语义名称/数量保留，不能只靠颜色区分。

## 行为

- Given 第九格有工具，When 移到第一格，Then 第九格清空，第一格可被快捷键选择且刷新后保留。
- Given 同物品 60/10 两栈，When 后者移到前者，Then 64/6，总量不变；无效索引/空源/死亡均不改变数据。
- Given 两格同类食物，When 使用第二格一件，Then 只扣第二格并恢复饥饿；饥饿已满不扣物品且没有成功食用音。
- Given 采集/放置/合成/攻击成功，When 投影结果，Then 显示反馈并发对应有预算的短音；失败不能发成功音。
- Given 足量原木与石材，When 合成并放灯笼后保存继续，Then 灯笼库存、体素与光照一致；拆除返还灯笼物品。
