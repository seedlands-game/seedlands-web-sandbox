# 独立准出检查计划

本文件由主任务维护，补充已批准 spec 的用例细节，不调整准出范围或阈值。所有运行结果仍待实施后取得。

## 分阶段准入

1. 模块提交：检查导出接口与 contracts 一致，具有实现前 RED 与确定性 GREEN；不得把未来主线需要调用的空方法标记完成。
2. 内存会话：同核协议/调度/物理/流体和旧档迁移闭环，断言没有直接客户端状态写入。
3. 浏览器接线：证明确实存在独立 Worker，冻结 GameLogic Worker 时 Authority 继续运行；只测试时创建 Worker 而生产继续同线程不予准出。
4. 自然旅程：真实键鼠走岸、跳跃上岸、连续跳搭/下挖、落地、入水和持久化；坐标快照仅辅助判定，不能替代画面轨迹。
5. 设备与视觉：前台同机 A/A、2/3 pool A/B，记录分辨率与 DPR，不用 headless 高频代替自然前台表现。

## 必须复查的几何旅程

| 场景                   | 观察规则                                                                   |
| ---------------------- | -------------------------------------------------------------------------- |
| 一格岸，只按前进       | 身体未越过岸顶则被侧面阻挡，不发生向上位置搜索                             |
| 一格岸，前进+Space     | 在水中上浮或水面合法起跳，经逐步轨迹越过岸顶后落地；单步位移受速度与dt限制 |
| 岸上方低顶             | 头顶受阻停止上升，不能从侧面瞬移到低顶上方                                 |
| 连续跳搭               | 按住Space并真实放块可连续合法起跳；脚下无支撑时不能额外空中起跳            |
| 快速向下挖掘           | 去除真实支撑后立即自由下落；高速仍不能跳过下方薄平台                       |
| 中心格挖空、邻块仍承托 | 新合同允许身体真实接触邻块时仍受支撑，不能下穿相邻固体                     |
| 所有脚底支撑挖空       | 与中心格场景分开，必须落下；不能把侧面接触当落地                           |
| 走下一格并后退         | 下落由连续运动完成，落地后能后退或再次跳跃，不依靠常规传送脱困             |
| 灯笼、角落、窄通道     | 统一注册形状，主观模型与真实碰撞调试线框可对照                             |
| 生物跨高度差           | AI只提交跳跃/移动意图，轨迹经过统一物理；不能在导航tick直接改变y           |
| 半身擦过水边           | 浸水量由身体覆盖体积变化；眼睛入水与身体浮力分别观察                       |
| 物件进出水流           | 吸附/水流/重力经过碰撞求解；穿墙与中心射线近似不能代替物件体积             |

## 调度与传输故障矩阵

- 相同physicsHz，不同renderHz/消息批量方式：重放同输入和提交序列，逐tick权威状态相同。
- 不同physicsHz：按事前RED测试给定容差比较跳高、落点和行程，不要求跨步长逐位一致。
- GameLogic阻塞500ms：Authority快照继续变化、输入直达、render刷新；不是仅独立clock数值增加而位置/接触停算。
- 主线程阻塞：Authority实际继续积分；承认该段主线程无法绘图。恢复时有限同步，无巨大dt或任意高度跳转。
- pause/blur/hidden：输入立即清空，会话通过可靠暂停/恢复确认；目标时间、积分时间和UI时钟各有明确语义。
- 0/50/150ms transport：输入确认、历史重放、缺失碰撞版本重同步；事务重复只产生一次库存/编辑效果。
- 错误epoch、过期AI、旧Mesh/流体candidate：拒绝且计数，不能写入当前世界。
- pool队列饱和：有限队列+字节背压，fluid保留槽可用，远景最终进展；消息积压不导致无限内存。
- 失效candidate或计算Worker崩溃：frontier租赁归还，版本匹配后能再次提交，不能静默丢失水流。

## 数据与性能检查

- 老版本玩家眼睛坐标和物件中心坐标明确迁移到统一脚底原点，重载后位置不整体偏移。
- 水位与源标记：single edit、edits batch、buffers batch逐场景等价，保存/重载同样一致。
- 权威Worker物理热路径不能触发同步makeChunk、完整世界快照复制、网格生成和长寻路。
- 客户端不得new GameServer并继续推进完整实体/世界；允许带revision的只读镜像与本地玩家同核预测。
- F3+B实际线框来自物理定义，显示权威/预测来源；关闭后零额外线框draw call和调试快照请求。
- A9性能阈值、负载和原有视觉效果保持批准spec，不通过换空场景、降内部渲染尺寸或放宽阈值过关。

## 证据分工

确定性核心由Vitest证明；实际异步接线和真实输入由change Playwright证明；轨迹自然、水面和碰撞箱可理解性由Midscene及主任务原始帧复核证明。长期基线几何变更由非实施者Sol/xhigh审核，记录请求模型/effort、被审spec hash与实际结论后才能修改基线口径。
