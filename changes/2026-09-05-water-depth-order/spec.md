# 水体深度与后处理顺序

## 背景与目标

真实林地镜头出现蓝色水带覆盖近处树干。核对发现水体透明层被追加在UI层之后，可能越过后处理截点而失去主场景深度。必须先用遮挡fixture复现，不能仅看反射开关计数。

## 范围与明确不做

确认并修正水体层的合成位置：处于世界几何之后、UI和后处理终点之前。保持独立水层以免反射相机递归绘制水体；不改生成器、水位或流体规则。

## 决策

使用PlayCanvas现有层组合公开接口；先以真实不透明墙遮住水体，对比有水/无水的墙面截图。应逐像素相同，水体不能污染前景。

## 行为

Given 水体在墙后，When 水体生成或删除，Then 前景墙面颜色不变。Given 无遮挡河岸，Then 水体和真实倒影仍可见；High后处理处理整个世界，UI保持独立。

## 测试设计

`e2e/water-depth-order.spec.ts` 先RED：固定镜头/时间/悬空fixture，墙后水体切换时前景截图不得变化。父昼暮夜矩阵补Midscene可见排序与材质检查。

## 验收与证据

- [x] Midscene：自然林地/河岸无水面覆盖近物。
