# 体素工具可玩样板

## 状态与目标

- 状态：Delivered；类型：Agile。人类审核与合并待完成。
- 用户授权：参照已对齐路线自主推进，明天停在能看到效果的可交付小边界；额度上限包含 buffer，不以耗尽为目标。
- 基线：`4197bda`；对应路线 WP05 的第一组工具样板，给 WP06/08 提供现有玩法消费者；不宣称完成这些工作包。
- 玩家结果：现有木斧、石镐具备清楚的像素立体轮廓，手持和掉落一致，采集/单次动作能自然挥动并回到原握姿；现有制作、丢弃、拾取循环仍可玩。

## Scope / Decisions

- 修改 client 表现计算和 app 模型装配、手持表现；复用现有物品 ID、配方、权威动作、库存、存档和 WebGL2 后端。
- 工具使用紧凑像素图挤出模型，以共享网格/材质供手持和世界掉落消费；不为每个像素创建 Entity，不引入新依赖或渲染管线。
- 像素图和颜色是内部第一方样板；不冻结公共资源包、rig、组件、插件或存档合同。当前没有剑物品，不伪造剑的玩法语义。
- 动作只影响表现；单次动画起止均回到静止，循环采集姿势连续；连续相同的一次性事件可重播，停止采集平滑收手。
- 不增加客户端冷却 UI、伤害时机、预测攻击、连招、ECS、武器数据或新世界生成；完整资源/动画合同后续单独审阅。

## Behaviour / Test Design（实施前）

1. Given 木斧/石镐，When 创建手持或世界模型，Then 使用相同像素定义和共享网格，轮廓不同且都有真实厚度；体素内部接触面不输出。Vitest 检查图形、面数、索引/法线/颜色、厚度和有界网格。
2. Given 单次攻击/放置/进食表现，When 动作起止，Then 姿势为静止，途中可辨，持续相同事件可以重新开始。Vitest 覆盖端点、周期、非有限时间和重播；Playwright 连续原始帧补视觉证据。
3. Given 持续采集，When 松开鼠标或切换工具，Then 结束旧动作并收回，手掌/袖口保留；只读验证已有服务端采集结果。Vitest 生命周期和 Playwright 真实输入。
4. Given 通过正常库存/配方获得工具，When 选择、拾回并存退重进，Then 工具数量和物品 ID 正确、模型一致且无残留。Playwright 可用 Harness 经既有生产库存/World.edit 路径布置材料和掉落物观察通道，交互使用真实 UI/鼠标；不把布置当自然游玩证据。丢弃仅验证既有调试 UI `/drop` 后自动回收，普通玩家快捷键尚未实现。
5. Given 桌面/窄视口和低画质，Then 可见工具不遮住准星，关键轮廓保留。截图观察；不宣称设备级性能或完整美术批准。
