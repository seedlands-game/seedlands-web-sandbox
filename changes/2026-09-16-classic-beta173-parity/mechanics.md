# 可观察玩法与算法合同：逐机制工作量 v0.1

目标不是“有同名内容”，而是排除红石电路、多维度和联机后，单人玩家从启动到退出所经历的 **b1.7.3 行为等价**，独立制作的美术/音频达到**感知体验等效**。本表把 [inventory.md](inventory.md) 的 M01–M36 共用系统预算拆成 129 个可单独登记有来源 reference case、RED 与验收的子项；**各组小计就是 M 行金额，不可重复相加**。1 PD=熟悉项目的工程师 8 小时有效工作，含设计、实现、测试、修复。数值是量级估算，不是已测耗时。精确算法、常量和事件顺序必须先有可靠资料；本地不运行 b1.7.3，本表也不能当成原版事实。

验收等级：`D` 同 seed/输入/初态的确定性逐 tick 状态对照；`P` 数值轨迹、频率或分布对照；`V` 视频/截图/交互手感并排评审；`A` 独立原创音频盲测。可受浏览器平台影响的时间或 GPU 结果固定平台边界和容差；容差必须先注册，不能验收失败后放宽。每行至少一条正例、边界/失败例和存档恢复例（若有持久状态）。

## 必测序列，而非单点演示

1. 固定 seed、新世界第 0 tick 到第 1 天夜晚：同输入序列记录区块/光照/生物/天气/背包/玩家位置，每阶段比对；更换 seed、世界边缘与跨区块单列。
2. 移动与建造：步行/跳/落/泳/梯/船/矿车（Beta 1.7.3 不引入后期冲刺）；挖一半转目标、临界工具耐久、快速放置、半砖/楼梯/双格冲突；区块卸载再返回。
3. 生存循环：木→石→铁→钻、夜战、受伤/食物/死亡/床重生；农作、动物/狼、钓鱼、地图；保存/加载每段状态不变。
4. 系统耦合：放/拆火把跨区块重新照明→敌对生成变化；液体淹火、火点 TNT、天气灭火；树叶衰减/随机 tick/物品掉落；AI 在门/水/落差/半砖周围追踪与卡住重算。
5. 视觉/音频：同一脚本双画面/双盲测记录 UI、材质、动画、镜头、音量/混音、静默段落；原创资产不能与原版字节对比作为通过标准。

以上是测试设计；[逐项表](reference-cases.json)现为 129 个机制子项中的 110 项绑定了有来源的**局部** expected，另 19 项属于本项目 Harness、工程治理、性能或原创体验合同，已绑定[项目预期候选](project-contract-expected.json)。110 项尚未覆盖完整初态、轨迹和反例，19 项未获审核/固定夹具，**没有任何通过结论**；补证入口见[工作清单](reference-worklist.md)。本期明确不运行原版；无法从可靠资料确定的玩法机制保持 `PARTIAL_REFERENCE_GAP`，不能从 Seedlands 测试结果反推原版常量。
