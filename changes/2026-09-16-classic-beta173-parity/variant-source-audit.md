# b1.7.3 可观察变体来源审计

范围是 `inventory.md` 当前纳入普通单人主世界的 97 方块、106 非方块物品、30 实体/派生态。固定源码候选为 [`740c583`](https://github.com/jacobo-mc/mc_b1.7.3_release/tree/740c583901e1ff1150e9ef37e37dab5bc0e4f807)；它定位 raw 值、位域和 NBT，不证明与官方 jar 逐方法等价。`排/存` 只在其变体会由已保留路径产生时列为反例，不计入可实施分母。

“一个 metadata 范围”不等于用例已关闭：下列 `有限值` 是建议逐值或参数化生成的状态分母；`无界` 是必须有边界/保存恢复/反例的族，不能伪装成穷尽枚举。

## 量化结论

在现有 522 个父 case 之外，[版本化子例表](variant-cases.json)已经登记至少 **618 个有限变体子例**：方块 346 + 物品 153 + 实体 119。它们是最小可分开断言的状态，不含每个父 case 已有的基础 happy-path。另有 8 个开放状态族单列为未关闭的覆盖分区，不能被 618 行的通过率掩盖。

| 面   | 有限子例计算                                                           | 无界或组合 NO-GO（未纳入 618）                                                  |
| ---- | ---------------------------------------------------------------------- | ------------------------------------------------------------------------------- |
| 方块 | 346：原始 metadata/ID 状态、有限 TileEntity 枚举和有限邻接拓扑，见下表 | 告示牌文字、箱子/熔炉库存、火的可燃邻接组合、流体跨格演化、方块实体保存         |
| 物品 | 153：煤 2 + 染料 16 + 44 个纳入耐久族各 3 边界 + 地图 ID 3 边界        | 13,050 个可普通取得耐久 raw 值、地图 ID 与地图像素/探索状态、stack count/容器链 |
| 实体 | 119：特有的有限派生态、大小、颜色/剪毛、画作、载具类型和投射结果       | 玩家/狼 owner、实体 ItemStack、AI 路径、精确 RNG/tick、库存与全部 NBT           |

`13,050` 是普通纳入工具/护甲/打火石/钓竿/剪刀的 raw 耐久取值总数（逐件 `0..maxDamage`）：5 种材质 × 5 种工具，加 4 种普通可得护甲 × 4 槽位，再加三种单品。它不应人工拆成 13,050 行；每个耐久族至少要有 `0`、中间值、`maxDamage` 仍未破损、再受 1 点伤害触发 `itemDamage > maxDamage` 破损的参数化例，并由实现另做全域性质测试。链甲属于 `存`，未计入该分母。来源仅是[固定重构源码的 `ItemStack.damageItem`](https://github.com/jacobo-mc/mc_b1.7.3_release/blob/740c583901e1ff1150e9ef37e37dab5bc0e4f807/1.7.3-LTS/src/minecraft/net/minecraft/src/ItemStack.java#L124-L138)候选，尚非官方 jar 真值。
