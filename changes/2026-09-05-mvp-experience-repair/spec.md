# MVP实玩反馈：实体物理、连续交互与视觉还原

**状态：Delivered。用户已明确授权本地自主SDD、并行Sol/Terra实施和新增20个百分点额度。**

## 背景与目标

用户已实际试玩原MVP，并在2026-09-05确认音乐验收通过，同时给出七项未达预期的问题及两张真实画面、一张Living World UI Concept原型。原父合同的部分视觉判断过于宽松，不能用既有Midscene通过否认用户反馈。本change以用户当前明确要求为最新权威，完成可实际操作、具真实三维物件与统一游戏视觉的修订版；保留原分支全部上游成果。

## 范围与明确不做

1. 掉落：实际三维材质/贴图，服务端重力与体素碰撞；掉落会落地，移除支撑后继续下落。玩家2.25米附近吸附，最终接近才拾取，不需精准踩中；背包满保留实体、不穿墙吸取。
2. 采集：按住左键可连续破坏并转向下一方块；松开、失焦、暂停、打开UI、死亡停止；保持原硬度、距离、物品原子性和服务端权威。
3. 模型：手、手持工具/方块是PlayCanvas真实网格与材质，并有持握/挥动/采集动画。三类生物有统一体素低多边形模型、纹理、清晰轮廓/面部/关节，替换当前平面SVG手和胶囊拼装造型。掉落与手持同一物品共享视觉定义。
4. UI：直接还原所附原型的黑曜石纹理、细黄铜装饰、宝石青强调、图标状态槽、紧凑居中快捷栏及其上生命/饥饿；暂停/设置/主菜单同体系。避免HUD相互重叠和工具遮挡，普通玩家视图不显示右侧调试实体列表。保留8快捷槽和现有玩法，不伪造等级/护甲/魔法或原型中的未实现内容。
5. 流体：新增服务端有界、确定性的体素水模拟：重力向下、地面横向扩散、障碍阻断、打开缺口后流出、移除源后回退；跨Chunk、卸载重载与存档恢复一致。表现有水位/表面与流向，修正悬空方块水墙、侧面反射及错误透明排序。仍有真实水面反射，但只在合适上表面按视角/粗糙度混合。
6. 方块交互：同一正式raycast作为目标来源；可操作距离内给目标体素三维轮廓，超距/遮挡/无目标/UI阻挡时隐藏；目标名称/物品缩略图用顶部悬浮信息框，移除底部目标文字替代高亮的方案。采集进度与目标对应。

7. 太阳：由世界时间决定世界方向，与主光源和阴影共享方向；固定时间转动相机时太阳在视野内移动或移出视野，不再是屏幕贴图。

仍不接AgentServer/LLM，不做联机、完整生态经济、一般刚体引擎或高精度流体压力/海洋模拟。流体的队列、每tick工作量与激活范围必须有显式上限，不能每帧扫描整个世界。不能删除用户存档或重解释原Voxel数值；任何新水位/速度格式必须给出旧档兼容、校验和恢复用例。原generatorVersion=2的基础地形保持不变，水动态作为权威编辑层。

## 关键决策与协作边界

用户要求主agent负责规划、核心设计、整合验收，具体开发尽量交Sol/Terra。共享worktree为codex/playable-world-mvp；各agent只修改约定模块，主agent处理跨模块接线、冲突、全量验证和本地commit。不得复制其他未提交worktree，不push。所有新增行为先测试RED再实现；子任务详细设计可补在本change的独立中文设计文档，不以口头规划代替合同。

- Sol：流体逻辑/存档/网格与水面效果；不编辑gameplay-runtime、实体模型、UI或player-controller。需要Game接线时提交明确补丁建议，由主agent落地。
- Terra实体：world-item重力/碰撞/吸附、必要非玩家实体落地；拥有gameplay-runtime及新增物理模块，不编辑水、模型、Game/UI/player-controller。
- Terra模型：物品/生物/第一人称真实模型与资源生命周期；拥有gameplay-entity-presenter和新增模型模块，不编辑UI/Game/server。主agent接入viewmodel生命周期并移除旧SVG手。
- 主agent：连续采集、target高亮/信息框、HUD/菜单还原、所有跨模块集成与准出。

所有模型与美术资产必须可追溯；优先自有网格/生成贴图，外部资产记录许可，不使用来源不明的Minecraft资源。3D网格可按用户授权自绘，UI图像使用已有/生成资产而非CSS伪造图像。原型是布局/视觉语言标准，不复制未授权品牌标识。

## 行为

- Given 在空中挖下原木/抛出物品，When 运行真实模拟，Then 掉落先受重力落至实体地面，玩家进入吸附范围后物品向玩家运动并只入账一次；墙后、满背包和死亡玩家不错误吞物。
- Given 一列两块可采集方块，When 玩家不松开左键连续瞄准，Then 两块依次按各自硬度破坏；When 松开/暂停，Then 后续块保持原状。
- Given 任一手持工具与三类生物，When 移动、挥击和观察侧面，Then 有真实网格体积、统一纹理/轮廓与正确关节动画；不再显示平面手图。
- Given 1280×720、1920×1080、用户截图比例及700px窄窗，When 游玩/开背包/暂停/设置，Then 所有必需控件可见可操作，无HUD相交、溢出和层级遮挡；状态值与服务端一致。
- Given 有底有墙的水池和外侧低地，When 玩家挖开池壁/池底，Then 水沿缺口下落并在低处有界扩散；新建障碍会改道，恢复存档保持同样水态；孤立无源流水回退。
- Given 可达/超距/遮挡方块，When 同一raycast目标变化，Then 轮廓只包围可操作目标，信息框和采集进度同步，目标离开后不残留。
