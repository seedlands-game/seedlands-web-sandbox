# 游戏外壳、暂停、设置与世界生命周期

**状态：Delivered；父 goal 授权自主 SDD，08:04 完成最终组合复验。**

## 背景与目标

让玩家从菜单进入世界，理解操作，在安全暂停时调整声音与画质，可靠保存退出并继续同一个世界。与已集成 Svelte 5 保留式界面、服务端世界和异步持久化沿用同一生产路径。

## 范围与明确不做

- 主菜单的新世界/继续、明确加载/失败状态、暂停、操作指南、声音/参考曲/画质设置、保存返回菜单。
- 世界内 Escape 或释放指针后暂停；地图/背包等主动释放指针的面板不被暂停菜单抢占。后台暂停模拟和声音；返回前台由用户恢复。
- 设置在菜单与暂停可访问。音量即时生效；画质保存并在下次进入应用，避免无提示重建世界。后续渲染 change 可将安全项升级为即时调整。
- 不做账号、多人、云存档、任意删除存档、复杂存档槽管理。继续最近的种子，新建输入相同种子明确表示继续该世界已有进度。

## 关键决策

1. 应用 Shell controller 持有异步状态与错误；Game 持有世界生命周期。单次 start/leave 串行，按钮在 busy 时禁用，失败不能销毁尚未保存的世界。
2. 继续每次从存储读取实际最近种子，不捕获首次启动的旧闭包。返回菜单必须先 await 当前世界保存，随后销毁 controller、world、实体渲染、音源、Worker、PlayCanvas。
3. 暂停冻结游戏时钟、玩家物理和 gameplay/AI；允许显示最后一帧和 DOM，恢复不补算墙钟暂停时间。暂停不会清空 world state。
4. 菜单/设置可键盘访问，有标题、焦点与状态文案。700px 宽窗口面板可滚动；reduced-motion 保留所有信息。

## 行为

- Given 主菜单，When 点击进入世界，Then 显示加载并禁止重复进入；成功才显示 HUD，失败可读且可重试。
- Given 世界内，When Escape 或浏览器失焦，Then 输入释放且模拟暂停；继续后从原位置/时刻恢复。
- Given 暂停，When 保存并返回菜单，Then 保存成功后才释放世界；保存失败保留世界与重试入口。
- Given 已退出世界，When 继续，Then 从最新持久化恢复玩家和编辑，不依赖旧闭包。
- Given 音量/画质设置，When 修改并刷新，Then 合法值恢复、损坏值回默认；本机参考曲不上传且刷新需重选。
