# 浏览器单 NPC Living World MVP

状态：Active，2026-09-09。基点 5d49ce8260d5b803c34a6fdf997b06d8b8e1b8c2，前置 PR #25 未合并，#24 已合并。用户已在当前对话完整讨论后明确授权自主实施并整体交付；此次授权覆盖本 spec 的角色、权限、存档和跨进程合同，不因历史 design-only/hash 待审再次停工。不得合并 PR。

## 需求与硬约束

核心体验：一个玩家与一个持久、有性格、有自主目标的 NPC 共处真实浏览器单机世界。NPC 在模型调用之间持续生活；可以回应玩家、拾取食用、移动、遇险撤退，留下真实且可恢复的后果。不得用聊天文案、瞬移、凭空获得物品或每轮重新生成 NPC 冒充活人感。

三层已确认：确定性身体/路径/执行/反射/基础行为/受限事件；Flash Vision（仅文本）事件触发 + 60–600秒时间兜底（默认180秒）；Pro仅上下文压缩，不做每日回顾或自动决策升级。事件提前调用后重置定时窗口；并发合并/退避/预算是独立保护，不以60秒硬上限阻止事件。无模型连接继续基础生活。默认128K、112K压缩软阈；可选256K/224K。无新意义事件可跳过兜底。暂停不累计待补调用。

世界身份、principal/resource/operation/target 通用；core 不认识模型/provider或Agent专属协议。Actor 是领域身体，角色投影只含自己、可感知对象和有来源事件。Authority仍唯一世界写者；浏览器主动连接本机认知服务，凭据只在本机服务进程环境；不实现 Dedicated、多人、LOD、World AI、离线补算、玩法规则扩展或图像输入。

## 交付阶段

A1：通用角色控制合同，持久 profile/目标/背包/记忆/终态事件，受限观察，目标执行、拾取食用、受击撤退/路径失效与fallback；Headless和Browser同能力。
A2：apps/agent-server 作为只持有认知状态的本机宿主；LangGraph显式图 + DeepSeek薄协议适配、受限工具schema、事件/定时调度、使用量与预算、Pro压缩、连接绑定/序列/重连对账。服务不拥有世界；缺API时明确不可用而非伪造模型输出。
A3：浏览器可直接创建/继续伙伴，展示姓名、目标、行为、说话与连接/思考状态；输入交流、调节兜底间隔、连接/断开；提供稳定演示入口和真实运行证据。调试信息与玩家界面分离。

## 测试设计与准出

- V01 无模型运行：同一NPC连续完成移动→寻找/拾取→食用或返程，饥饿/背包/世界掉落实际变化；多个tick不是纯文本动画。
- V02 玩家互动：玩家一句请求触发决策，NPC有与人格和现状一致的回应及计划；正常动作产生可观察后果。
- V03 中断：受击先执行层避险；障碍/目标消失有失败、重试或替代目标，不能卡死/瞬移；模型断线仍持续安全行为。
- V04 权限：绑定自身、局部感知、可见目标引用、未知/越权一致错误；旧epoch/请求序列/绑定/迟到决定不得写新世界。
- V05 持久化：同一个Actor身份、背包、profile/目标/摘要和事件cursor随完整checkpoint恢复；旧存档显式迁移；恶意/损坏字段不能部分污染现有世界。
- V06 调度：事件提前唤醒并刷新兜底；并发事件合并；暂停/恢复不补洪峰；无密钥/超时/429/坏工具/超预算返回具名状态，不重复副作用。
- V07 压缩：112K/224K软阈触发Pro；只处理冻结cursor前历史，新增事件不丢失；失败保留历史，硬阈以确定性摘要恢复；完整tool对与provider reasoning回传；不将私有推理写到玩家记忆/普通日志。
- V08 真实Flash Vision文本工具调用 + 真实Pro压缩，有usage、时延、输入来源和世界回执，不把mock当模型验收。复用用户明确授权的MIDSCENE_MODEL_API_KEY；直接运行时读取，不输出/复制密钥，不读.env。
- V09 真实浏览器玩家+NPC相处旅程、保存重入、对话/行为/掉落/身体对应。至少一段连续行动记录与早中晚截图，单帧不是活人感证据。
- V10 根verify:static、独立build、H1/H2与旧浏览器/近战门禁、新MVP e2e；独立源码审阅，语义提交、可读PR、最新SHA CI通过后交人类，不合并。

先取得缺失能力的可执行RED；模型智能和活人感另外保留观察预期：目标连续性、事件响应、后果真实性、人格一致性，每项0–2分，有证据才计分，目标至少7/8且否决项为零。该评分是本轮工程验收，不冒充用户研究。
