# 浏览器建造高度的可见边界

## 背景与目标

README已经明确浏览器只加载原型地形的垂直范围，实际为cy=0..1，即y=0..63。验收构造80米fixture时发现核心可以保存高处编辑、浏览器却不呈现；玩家在顶部继续放置也会消耗物品但看不到结果。

## 范围与明确不做

本次延续已存在的浏览器垂直范围，明确y=0..63建造边界，超界放置给出中文反馈并保留物品。统一范围常量供streaming和浏览器放置入口使用，避免双方漂移。指南与README写清楚数值。
不重构垂直streaming、远景高塔、生成器、核心无界坐标/World.edit、Headless或持久化格式。未来扩展浏览器范围须另作有性能证据的change；当前范围不得继续静默吞掉用户物品。

## 决策

浏览器能力检查位于BrowserGameplay.place，在调用权威placeVoxel之前返回失败反馈。它是呈现能力限制，不作为服务端安全权限边界；调试/Harness构造仍能验证核心无界数据，但不可把高处未呈现的fixture当作画面证据。

## 行为

Given 玩家站在浏览器顶层附近且有石块，When 右键试图放在y=64，Then 显示支持高度0–63，背包不扣，worldRevision不变。y=63以内原放置逻辑保持。

## 测试设计
