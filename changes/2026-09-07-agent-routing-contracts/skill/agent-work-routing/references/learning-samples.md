# 学习样本来源

以下只保留会改变路由决定的结论，不展开历史对话：

- [本任务](thread://01a07751-c72c-7ea3-82bb-03c9ce46b982)：形成了“固定合同→校验→完整交接→独立闭环”的工作单元，并要求批量工作先寻找确定性 runtime。
- [治理任务](thread://01a07695-485d-7141-82ec-5db5f1e15085)：父子范围、权限、预算和审批边界必须显式继承，文档规则不能冒充平台硬约束。
- [WASM 任务](thread://01a076cb-d2b7-7d63-8446-f42332d6c5a8)：长开发与独立验收需要不同职责；依赖门未满足时可并行准备，集成服从顺序门禁。
- [异步监控补充](../../../../2026-09-08-async-monitor-routing/spec.md)：长 CI 等待不应反复唤醒主任务；监控必须绑定 run、来源 SHA、截止时间和回报对象，且只在终态、超时或需要决策时回报。

这些是已核对样本和用户制定策略，用于解释默认路由，不构成模型性能对照。项目当前规则、用户直接选择和可用工具优先。
