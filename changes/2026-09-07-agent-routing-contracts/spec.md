# 分层模型路由与确定性执行契约

## 背景与目标

用户要求把已讨论的任务路由落实为全局渐进披露 skill、可校验交接脚本、通用批处理异步 runtime，以及 Seedlands 的资源与验收策略。只约束 agent 主动派发，保留人类的模型选择；嵌套派发继承边界并独立闭环。

## 范围与非目标

本 change 基于 origin/main 4197bda，独立分支 codex/agent-routing-contracts。Node 分支 8144135 保持原状，WASM→Node 合并继续待办。本次不修改游戏生产逻辑、不实际写线上表格、不部署或开启长期自动任务。

全局 skill 的可版本化源位于本 change 的 skill/agent-work-routing，验证后安装到 ~/.codex/skills/agent-work-routing；全局 AGENTS.md 只加入短原则与指针，保留其他内容并备份。项目规则引用全局 skill，并给出未安装时的本地交付源入口。交付记录区分已安装本机与其他机器尚需安装，不能宣称自动同步所有设备。

## 决策

- 先判定能否由确定性脚本/批处理完成，再选择模型。明确长开发 Sol/high；明确执行验收 Terra/high；限定资料提取 Luna/medium；纯文本机械扫描 Spark/xhigh；顶层设计/模糊问题/复杂 UI Astra/high，必要时升级。Luna/Spark 默认不开发、不做复杂语义审查。
- 人类选型不被重路由；其选定 agent 可自主按此路由派发子工作。subagent 负责单次闭环；跨请求复用的固定职责才用独立任务，实际工具许可/并发上限优先。独立任务创建仍需已有明确用户授权。
- 主派发者与所有子派发者必须先生成机器合同并通过固定脚本校验，再使用渲染后的完整交接文本调用工具。工具平台并无可注入的全局拦截器，不能宣称此脚本硬拦截任意直接工具调用。
- 合同至少包含版本/id、定位/类型、goal、上下文与输入、输出/所有权、范围与非目标、模型/effort/落地形式、可验证准出、资源需求、预算/终止条件、升级条件、权限依据与父合同引用、结果回报要求。子合同不得扩大父权限、写入范围或预算；固定单元不是只传“继续做”或敞口目标。
- runtime 提供一次准备、有限并发写入、真实读回校验、有限退避重试、稳定 item id/幂等键、断点状态、只重试失败项、状态查询/有界等待、取消/退出与审计。配置/输入/适配器漂移禁止静默续跑；成功项跳过。默认禁止非幂等写入的盲重试，写入结果不明标记需对账。
- runtime 使用 Node 22 标准库和受信任本地 adapter，不内置任何账号凭据或真实业务 API；审计不保存 payload/token/原始异常正文。明确定义超时与取消能保证的边界，不把超时当远端未执行。无 work 时等待，不让模型按行调工具。
- Midscene 视为用户预算口径下近零成本的 UI 语义断言工具，实际仍可能依赖模型/密钥；可程序化行为优先 Playwright，视觉语义用 Midscene，只有明确单步诊断需求才手动 CDP/UI 调试。不替换项目现有证据门。
- 项目性能采样由固定 Terra/high 职责协调，使用机器级阻塞窗口而非多个 agent 忙轮询。保留现有锁路径与旧 owner 格式兼容；等待有上限、取消不动他人锁、持有者退出后清理自身进程组再释放。普通功能测试不冒充有效性能证据。

## 行为与测试设计

实现前先写下列可执行用例并记录真实 RED；Node 原生测试隔离到临时目录/本地 HTTP，不调用真实线上服务。

1. 有明确 goal/验收/边界的 Sol 合同可渲染；缺验收、错误模型/effort、Luna 承接开发、子任务扩大权限/范围/预算、错误父绑定均拒绝。人类创建任务不受模型路由强改。
2. 相同输入渲染带合同 hash 的交接文本；校验失败不生成可派发文本。可输出完成/失败报告模板。
3. 批量本地 fixture 完成 prepare→write→read→verify；并发有界、临时失败有限重试、失败项可续跑、成功项不重写；输入/adapter 漂移拒绝恢复。
4. 写入超时/异常不能假装未执行；非幂等不盲重试；验证失败与写入失败分离；状态/取消/期限结束可恢复、审计不泄露 fixture 密钥和 payload。
5. 资源窗口第二调用阻塞等待，前者释放才启动；超时退出、取消等待不删除他人锁；子进程失败/中断/派生子孙清理后释放自有锁，未知持有者不自动抢占。
6. fresh agent 仅读 skill 与样本需求，能正确选择脚本/Sol/Terra/Luna/Spark，产生通过校验的闭环合同；不得向作者透露预期答案作为测试提示。

## 工作量与预算

规划口径为 4–7 PD；Sol 实施合计 6–12 agent h，Terra 验收 1–3 h，Astra 顶层/验收 1–2 h；工具运行 0.5–2 h；并行关键路径约 5–10 h，含 20% buffer 为 12 h（24h 连续口径约 0.5 日）。均为低置信度规划，非实耗。成本情景见 [预算记录](estimates.md)。父合同使用有界工作与升级触发，不能以未知账单伪造硬限。额度与费用在交付记录补实测可得值，缺失为 unknown；不创建 goal、购买或兑换 reset。
