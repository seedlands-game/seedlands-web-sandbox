## 意图、假设与边界

玩家可采集、合成木剑、装备，在有可读前摇的遭遇中战斗、连招、躲避、拾取并恢复存档。开发者能替换表现与玩法参数，复用同一执行器。长期服务物品、动作、战斗与模组注册路线，不宣称本次完成全部 WP 或任意代码插件能力。

硬约束：core 无平台依赖；权威状态唯一 owner；稳定 EntityId 不等于内部 handle；保持旧物品 ID、体素和存档兼容；动画不能扣血；WebGL2；不变更线上配置。

技术假设与准入裁决（R2）：D08/路线 6.5 的有界 ECS 组件化仍是已确认前置目标，但 bitECS 0.4.0 本轮安装准入被既有依赖阻断：当前 registry 缺少 svelte 5.57.0 所需 devalue 5.9.2 元数据，既有 minimumReleaseAge 无法完成验证。两次不同阶段的失败分别为 NO_MATCHING_VERSION 和 MINIMUM_RELEASE_AGE_VIOLATION；不重试、不改 registry、不绕过门禁。新增 manifest/lockfile 已完整撤回，EntityStore 未迁移，具体证据见 [ECS 准入记录](ecs/admission.md)。本轮继续交付可独立验证的物品、权威动作与动画；不会将此交付称为 ECS 已完成。ECS 待供应链元数据恢复后单独推进。模型和骨骼复用现有 PlayCanvas Anim 与 GLB 资源生命周期；不以性能为采用理由，不宣称降低 GC、复制或帧时间。

## 本轮可验收合同

1. 物品定义具有类型化放置、食用、挖掘、近战能力；全部既有物品/配方迁入有界、校验并冻结的定义合同，木剑直接走同一合同。普通堆叠不创建无用实例；无耐久等实例差异时不预建实例系统。
2. 一套权威近战执行器处理开始、前摇、命中、恢复、取消和有界输入缓冲；木剑两段连招与第二套节奏定义可复用。NPC 与玩家控制源不同但共用命中规则。命中点重新检查距离、遮挡、存活，单动作单目标最多提交一次。
3. 连点、切槽、死亡、目标消失、保存重进不能产生重复命中或绕过冷却；恢复不补发进行中动作的伤害。旧存档仍可读。
4. GLB 有界支持骨骼和动画，严格保留自包含、字节/节点/三角面/纹理上限与错误反馈；工坊导入、片段选择/预览、绑定保存、应用到游戏共用模型资源。至少一个真实 skin + clip 样例，资源释放可复验。
5. UI 展示权威攻击阶段/冷却与结果；角色表现消费动作事实，不通过模型名称决定伤害。木剑在工坊、图标、手持、掉落共用资产。
6. 同一领域命令在 Worker 和 Node core 宿主验证；现有 main 不包含 #17 的真实浏览器远端会话 UI，因此不得把 Node 领域/持久化证据冒充其浏览器重连验收。

非目标：全量 ECS、体素迁移、任意骨架重定向、多轨道、施法、耐久附魔、root motion、公网多人、#17 合并、插件市场。
