# 首次旅程引导与可读性

**状态：Delivered；Agile flow，父 Goal 授权。**

## 背景与目标

完整自然资源链已经可玩，新玩家仍须猜测合适seed和采石路径；主HUD小字对明亮场景对比偏低。提供可选推荐起点和简短生存路线，让已有功能从GUI自然发现。

## 范围与明确不做

新增推荐“林间河岸”按钮只填入已验证的 `mosslight-68` seed，不自动创建或覆盖世界；更新操作指南、HUD辅助字和双语README。没有任务系统、奖励、强制教程、生成器变更或新配方。

## 关键决策

推荐seed经纯宏观采样和真实浏览器验证：原点森林、附近约45米处有河水。玩家可以编辑字段或留空随机；相同seed仍继续已有存档。指南解释木板/木斧→阶梯取石→石镐/灯笼、树叶可得浆果、夜行兽危险和存退。

## 行为

- Given 主菜单，When 点推荐起点，Then Seed字段更新而世界没有自动开始。
- Given 自定义字段，When 编辑，Then 保留用户选择；加载中推荐按钮禁用。
- Given 操作指南，Then 能找到E背包、阶梯采石/跳回地面、灯笼和浆果的说明。
- Given 明亮游戏场景，Then 生命/饥饿与帮助文字更清楚，仍不遮住准星或快捷栏。
