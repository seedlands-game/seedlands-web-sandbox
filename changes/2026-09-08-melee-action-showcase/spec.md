# 木剑动作体验场

## 状态与目标

- 状态：Delivered；类型：Agile。
- 用户反馈：木剑已可见，但普通世界缺少稳定近身目标，现有第一人称姿态变化也不足以让人直观看出权威前摇、挥击、收招和第二段反向连击。
- 玩家结果：从开始页一键进入可重复布置的木剑动作体验场；进入后木剑已装备，静止训练目标位于有效攻击距离内，高对比地面/背景帮助观察两段相反方向的挥击。场内另有一个近身敌人，用于同时体验实体与玩家受击反馈。

## Scope / Decisions

- 保留现有木剑伤害、3 米距离、权威阶段、输入缓冲、命中复核和存档合同；只修改第一人称动作姿态与开发者体验场组合。
- 第一击采用清楚的右上蓄力到左下斜劈，第二击采用相反方向回扫；阶段仍只消费权威 `CombatSnapshot.active`，不以动画回调提交伤害。
- 开始页增加“木剑动作体验场”入口，使用独立固定 Seed。体验场通过现有 Authority 命令/动作入口清理自己的固定训练目标、铺设场地、传送玩家、给予并选中木剑；不改普通世界生成，不清理其他 Seed。
- 体验场提供常驻操作卡、“测试玩家受击”和“重新布置目标”；玩家受击按钮经 Authority 的真实扣血命令触发，不直接伪造表现。训练目标无自主移动，12 点生命值恰好让 5+7 的完整两段连击产生明确终态。
- 实体受击不再用纯色材质覆盖原外观；为每个原 `StandardMaterial` 建立保留原贴图的半透明红色受击变体，短时切换后恢复并随 presenter 释放。
- 玩家受击从同一次权威生命下降投影出 HUD 数值/生命区闪烁、短促衰减的相机冲击和合成受击音。相机冲击只叠加到最终渲染角度，不修改持久 yaw/pitch、移动方向或权威输入。
- 不增加新武器、第三人称玩家模型、粒子、风格化伤害数字资产、伤害数值或正式关卡/教程系统。

## Behaviour / Test Design（实施前）

1. Given 权威第一段/第二段动作，When 采样 windup/hit/recovery 端点，Then 两段的横向挥击符号相反、静止端相同，且最大轮廓差明显大于旧姿态。Vitest 先取得姿态断言 RED。
2. Given 开始页，When 点击“木剑动作体验场”，Then 自动进入独立 Seed，并在常驻卡中展示两击说明。Playwright 先因入口不存在取得 RED。
3. Given 体验场首次或再次布置，Then 固定 ID 的三个静止目标被替换而不重复，平台、发光背景、玩家位置与夜间时间一致，木剑位于快捷栏并被选中。Vitest 检查确定性命令计划，Playwright 读回真实 Authority/场景状态。
4. Given 玩家准星对准中央目标，When 按住左键跨过连击缓冲窗口，Then 浏览器原始帧可辨第一段斜劈、反向第二段和回位，HUD 仍显示权威阶段与 5/7 点命中结果。
5. Given 实体生命下降，When presenter 进入 0.25 秒受击窗口，Then 原贴图引用保留、红色染色使用透明混合，窗口结束恢复原材质；自定义 GLB 延迟接入后也注册同一变体。Vitest 检查材质合同，Playwright 截取命中帧。
6. Given 玩家生命下降，When 浏览器消费新权威状态，Then 同一 damage sequence 携带实际损失值，HUD 显示“受击 -N”、生命区闪烁，相机冲击先增强后归零且不改变输入朝向，并播放高优先级、区别于挥剑的合成音。Vitest 检查投影/衰减/波形；Playwright 通过场内 Authority 扣血按钮读回生命、HUD、相机与音频，夜行兽仍按真实夜间 AI 提供自然受击路径。
