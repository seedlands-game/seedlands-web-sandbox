尚需持续跟进的系统项：树冠与地形层次、真实植被密度、出生通路、生物实际动作、夜间多类方块照明。这些不会因本轮三个工作包静态通过而自动成为通过。改变世界生成必须另列版本兼容方案；保留在整体体验待办，不能用缩小植物宣称已经改变生成密度。

第二层源码发现：木门、梯子、火炬、栅栏仍缺少专用结构纹理，默认走通用噪点基底；单根栅栏没有横档，单薄板梯子没有实际梯档空隙。现有门/火炬缩略图分别显示薄板/细柱，与源码几何相符；此前“缩略图过期”的推断已被主线程直接查看 PNG 否定。后续应从材质与几何来源统一修复，再由既有生产链派生缩略图，不能盲目重跑同样输入或只换目录图标。细面 UV 按物理尺寸取样，火炬木柄/火头绘制必须核对真实采样区及自发光阈值。

本轮后态采集状态：GUI_LOCKED。Cua `run19`/`run20` 未形成可接受的试玩录像；主线程查看 `run20-mission-control.png` 确认 macOS 要求 Touch ID/密码解锁。没有尝试认证或以其他执行器绕过。上表后态保持待录制，解锁后继续同一矩阵，不把新的源码、静态测试或失败录制当作已看过修复后效果。

继续阶段更新：已解锁并取得 `run25-resume-forest/final.png`，其对应录像可解码。主线程确认普通蘑菇棕色、地面绿色收敛、九格槽位边框减轻；花朵黄条、草叶直杆与菌帽尖底仍未达标，已据此再次修源。该帧属于再次修稿前，不是最终验收图。`run21` 是隔离资料空存档菜单，推荐 seed 首次进入后解除暂停；这里“继续游戏”指解除暂停，不是恢复用户旧档。

Cua 后续 native 路线出现 ScreenCaptureKit 捕捉失败与 AX 无法绑定。`desktop_unlocked:false` 单字段不是 macOS 锁屏证明；新的桌面截图显示已解锁。已通过同一官方 Cua 的 typed browser 路线取得 exact bind 与 mutation_allowed，用 Jev 继续选择实际观测到的页面动作；不启用 Playwright 或旧 Browser 执行器。

整体森林根因与版本边界：`voxel.ts` 固定森林树源密度、四格树干与多层宽叶冠会造成低顶；`safe-spawn.ts` 只寻找可站立空气，不评估开阔视野。改变树形/密度须新增生成版本并保留 v10；改变出生坐标须版本化新世界初始化、保持旧玩家位置。后续先为这些行为冻结独立 spec 与多 seed 样本，而非直接重写当前版本。草顶逐像素噪点和色阶跨度属于呈现源，本轮继续收敛，不动世界体素。

资产链复核必须区分：定义、生成的图像、最终选用的资源、游戏内采样、用户实际看到的轮廓。图标和世界可有适合各自视角的画法，但物品身份、材质色彩及形态必须对应。保留用户显式外观覆盖，未证明资源过期前不进行迁移。

所有浏览器与重型检查通过默认性能窗口；录屏包含相邻桌面时只本地保存。完成后记录源码 SHA、实际目标与画质、材料路径、观察结论和仍缺口。
