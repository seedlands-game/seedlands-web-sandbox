# 第一期体验与复现

从仓库根目录运行 `pnpm dev`，打开终端给出的本地网址，新建生存世界。这里的 ESM Pack 是仓库构建出的玩法 JavaScript 模块，启动时加载经过锁定摘要校验的文件；不是需要另行购买或发布到 npm 的整合包。

## 木、石、铁成长

1. 左键持续采集原木，走近拾取，按 E 打开背包。先把原木制成木板，再合成工作台；选中工作台，右键放置。
2. 对准工作台右键打开。在 3×3 工位的第一排放三块木板，中下两格各放一块木板，合成木镐。工位点击默认移入一件，可选择整组转移。
3. 木镐采石，制作石镐；石镐开采煤和铁矿石。镐的品质决定可采矿种，使用后显示剩余耐久；木、石、铁的耐久上限分别为 60、132、250。
4. 工作台八格石块围成空心环制作炉体。放置后右键打开，输入放粗铁，燃料放煤或原木；每份铁需 5 秒逻辑时间，煤燃烧 20 秒、原木 8 秒。输出可取回；装满时不会吞料。
5. 三块铁锭加两块木板按同样镐形排列制作铁镐。八格木板环制作箱子，放置后可存取物品。离开并重新进入同一种子世界，核对箱子、耐久及炉体进度。

采叶获得浆果，在背包选中后食用。保留附近叶片可再生有限食物；用普通放置建造墙体抵挡怪物。死亡会掉落背包物品，点击复活后可回到原处拾回。创造模式从背包显式切换，目录与生存库存分开；切回生存需要安全落脚位置。

## 可重复验收

- `pnpm test:composable-gameplay`：本 change 浏览器实际输入、成长、模式、替代玩法和生存反馈。
- `pnpm exec vitest run tests/server/composition/overworld-survival-days.test.ts`：两日普通动作场景，包含建造、夜间阻挡、可再生食物、死亡/复活拾回。
- `pnpm exec vitest run tests/server/composition/alternative-playbooks.test.ts`：独立点击转换和纯建造玩法的真实 Headless 入口。
- 替代 Playbook 的构建与运行见 [examples](examples/readme.md)，公开接口边界见 [API 候选](api-candidate.md)。

自动成长旅程只布置有限可采原料与站立区域；工具、工位及材料产出均来自正常输入和事务，不直接发放成品。两日 Headless 的 NPC 攻击是脚本驱动正常动作；Browser 生存反馈用受控开发者伤害触发死亡 HUD，两个证据覆盖不同边界。最终通过与失败记录以交付快照为准。
