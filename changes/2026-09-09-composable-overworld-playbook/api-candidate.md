# 模组 API 候选与本期边界

作者入口为 `@seedlands/game-core/mod-api`，宿主入口为 `@seedlands/game-core/server/composition/host-api`。作者定义内容、机制及所需权限；宿主独立批准权限、验证锁定产物并建立每世界组合。当前是经第一方和两个替代样例检验的候选接口，没有宣布通用第三方生态或稳定长期 ABI。

| 能力         | 当前入口与责任                                                  | 验证边界                                                                         |
| ------------ | --------------------------------------------------------------- | -------------------------------------------------------------------------------- |
| Pack 与装配  | `definePack`、manifest、模块依赖及 provider 选择                | 确定性注册、冲突/缺依赖/不许可替换拒绝；宿主在导入前核对摘要                     |
| 内容         | `defineContentModule`、物品/配方、actor profile、工位及可选生态 | 每世界只读定义；不依赖第一方物品 ID；未知定义在建立候选世界时拒绝                |
| 状态与规则   | 注册 state/operation/rule、候选提交、事实事件                   | 单 owner；保留原始调用者；跨实体与库存等 owner 的预备提交；没有任意 I/O 回滚承诺 |
| 正常角色操作 | 库存、模式、Needs、Combat、采集/放置、工位和地面食物模块        | 玩家和普通 NPC 经同一权限/动作边界；模块不能借自身权限提升调用者                 |
| 合成匹配     | `defineCraftingProviderModule`、`CraftingProviderV1`            | 冻结输入和有界槽位消耗计划，共享事务再次校验实例、精确材料和完整输出容量         |
| 宿主         | Browser Worker 与 Headless 的共享装配/保存                      | 同一锁定 Pack 与检查点身份；不承诺跨不同内容摘要自动迁移                         |

样例见 [examples](examples/readme.md)。点击转换样例替换了合成匹配条件，纯建造样例移除了合成、Combat、Needs 与初始生态；两者保留标准库存、方块和模式以复用正常交互。第一方 Overworld 显式声明默认 provider、内容和生态，不能作为缺失能力的隐式 fallback。

本期保留有限的 `ActorArchetype`、导航/行为类型和第一方体素生成器。配置可改变角色生命、近战、死亡掉落与可选开局生态，但没有提供任意行为树、模型资产市场、任意远程 ESM、模组热更新或未知体素 ID 迁移。ESM 是可信代码装配形式，摘要和权限合同不构成 JavaScript 进程隔离沙箱。

增加新玩法时先复用这些真实入口。若需要扩展新的核心原语、内容 schema、权限资源或存档语义，应独立登记可验证合同；不要跨包读取内部 owner，也不要通过复制第一方内核形成另一份权威状态。
