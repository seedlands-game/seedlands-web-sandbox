# S4 可再生采集食物

状态：Implementing；承接已批准可再生食物与多日游玩，不增加农业、繁殖或睡眠系统。

第一方完整树叶会按逻辑时间成熟并落下浆果，玩家经正常 world-item 拾取/进食。采集不要求砍掉叶子；原有破坏叶子掉浆果行为保留。机制模块只接收显式 sourceVoxel、drop item 与间隔，不能硬编码 Overworld 物品名。

固定首版规则：每120逻辑秒检查存活生存玩家周围水平4格、脚下整数 y 到上方8格的已加载体素；确定性按玩家ID及坐标排序，叶子下方必须为空气。将相邻采样去重，每次最多16处，落点为叶子下方空气格中心并使用既有 world-item 物理。落点1.5格内已有同种食物时不再产出；玩家捡走后下一个成熟周期可再获得。只读取已经可用的体素，不为此强制生成远处世界。样本和上限是可解释产品边界，不声称性能优化收益。

不建立独立计时 Map：成熟时机由已有 ModuleLifecycle interval 与其 checkpoint 持久化；资源真值使用现有 ECS world-item。一个 registered system commit 同时准备全部掉落实例，最终重新检查参与玩家身份/模式/位置、叶子与空气、已有同种掉落及 ECS 新鲜度。空候选是 no-op；失败无部分掉落。没有模块/缺合法食物内容的组合不隐式补默认食物。

RED/GREEN 包括：第一周期→正常拾取/移除→第二周期再生；保留地形；场内已有浆果阻止重复；creative/dead/缺叶子/缺空气不产出；同位置多玩家不重复；中途保存恢复沿同 schedule 只执行一次；权限拒绝与最终clone失败不产生部分物品。Browser还需正常观察/拾取/进食与多日夜怪压力验收。
