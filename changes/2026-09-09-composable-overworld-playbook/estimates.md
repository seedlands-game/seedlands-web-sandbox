## 3. Token、credits 与 API 等价

尚无此 change 的模型分项可归因用量。用于敏感性分析的全阶段原始 token 假设如下，不能由工时机械推导；正式实施后用真实阶段轨迹替换：

| 类别                   | 正常假设  | 保守假设   |
| ---------------------- | --------- | ---------- |
| 未缓存输入 U           | 1,000,000 | 2,000,000  |
| 缓存输入 C             | 6,000,000 | 12,000,000 |
| 输出 O（包含计费推理） | 150,000   | 300,000    |
| 合计，仅原始计数       | 7,150,000 | 14,300,000 |

这些是跨长上下文、多次验收与返工的假设区间，未校准前不称为预测准确的计费预算。缓存率、压缩、工具输出和多次验收会显著改变结果。

| 执行归属   | 模型/effort/速度                               | credits                | API 等价 USD           |
| ---------- | ---------------------------------------------- | ---------------------- | ---------------------- |
| 当前主线程 | 用户决定，本轮不读取配置；精确计费映射 unknown | unknown                | unknown                |
| 子 agent   | 本轮未派发；未来独立评审另冻结合同             | 尚未纳入可计算模型分配 | 尚未纳入可计算模型分配 |

按模型计费时，分别计算 `(U × 输入费率 + C × 缓存费率 + O × 输出费率) / 1,000,000`，再按真实速度/服务档适用倍率处理。未获得模型分配与倍率前不把一个模型的费率套给全部任务。credits 与 API USD 是不同口径，不能互相假定兑换，也不能称为订阅增量账单。

2026-09-09 已读取官方 [credits 定价](https://learn.chatgpt.com/docs/pricing)与 [API 模型比较入口](https://developers.openai.com/api/docs/models/compare)。前者为每百万 token 的分项费率；后者不能单独确认此用户所选执行模型的精确计费档。本轮不据此读取或更换主模型，不伪造精确美元数。

原始 token 假设保守值加 buffer 为 `14,300,000 × 1.2 = 17,160,000`，仅供规划，不是 Goal 工具预算，也不代表已授权消耗。用户未要求创建跨轮 Goal、购买 credits、使用 reset 或更换付费档，本轮均不执行。
