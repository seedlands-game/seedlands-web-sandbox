# S5 合成匹配 provider 与独立样例

依据批准合同 T13。标准物品、库存事务与输入入口继续复用；合成匹配独立为版本化 capability。第一方 Overworld 显式加载无序匹配 provider；点击转换样例只加载自己按选中槽匹配的 provider，不加载 Overworld、Needs、Combat 或工位。

匹配器只获得冻结的配方、槽位与选中索引，返回需要扣除的槽位和数量。共享事务验证每个槽位、实例身份、总消耗与配方输入一致，再在独立候选上扣料、添加完整产出；容量不足、非法计划、不稳定候选或权限拒绝不能修改权威状态。不同匹配器只改变匹配与交互条件，不取得直接写世界权限。每世界内容显式解析 provider，未声明 provider 的组合内容不能回落到默认合成。

RED：选中槽不匹配时，其他槽有材料也不得转换；切到材料槽后按同一正常 craft 输入完成转换；恶意重复槽、过量、少扣与错误实例计划被拒绝且库存不变；完整产出容量不足不能扣料。无默认合成 provider、无战斗/需求的真实宿主开局、加工与跨宿主恢复作为后续集成门禁。

样例 ESM 使用公开 mod-api 构建。宿主仅允许明确的样例 Pack ID 与预设权限，不把 manifest 权限请求自动当批准。浏览器仍校验锁定产物摘要；示例使用独立 world seed 和检查点身份。

两个独立样例使用 `sample:wood` / `sample:stone`，不复用第一方物品 ID。真实 Headless 开局、普通采集、选中槽匹配、产出和放置共 2 项通过；自定义物品的手持与掉落模型也显式接收当前世界定义，避免查询第一方静态表。无专用贴图的自定义物品在 UI 使用通用方块图标。

匹配与事务定向测试 16 项通过，模型/手持/掉落回归 20 项通过。保留最初缺失模块、隐式 berry 依赖、无生态装配启动误拒绝和自定义物品模型查询失败的 RED 记录。日志分别为 `/tmp/seedlands-s5-provider-inventory-green.log`、`/tmp/seedlands-s5-render-regression.log` 和 `/tmp/seedlands-s5-alternative-green1.log`。

T10 的真实 Headless 两日场景已通过（`/tmp/seedlands-s4-survival-days2.log`）：普通采集与放置建造庇护所，保留叶片获得可再生食物，夜间普通 NPC 攻击被墙阻挡，开门后死亡、掉落与复活拾回。NPC 攻击由脚本调用正常角色动作；不将此称为自主 AI 策略验收。

状态：独立样例、双向跨宿主与本地全量门禁已通过；最终独立审阅和 PR/CI 见 [S6 验收](s6-acceptance.md)。

独立样例已纳入与第一方 Pack 相同的 ESLint 公开 API 边界；新增负例在原配置下实际失败（内部入口未拦截），修复后 14 项导入边界测试通过。样例目录使用显式 kebab-case 命名规则，未忽略源文件或放宽内部导入检查。
