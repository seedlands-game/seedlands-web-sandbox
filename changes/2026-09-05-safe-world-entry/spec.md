# 新世界安全出生

**状态：Active；父 Goal 已授权自主实现。**

## 背景与目标

当前新玩家固定出生在 [0,34,0]，地形高于该点时有埋入地面风险，水域也未排除。父合同要求多个 seed 能自然开始生存。为新世界选择有干燥地面和足够头部空间的确定性起点，已保存玩家的位置仍按存档恢复。

## 范围与明确不做

只改变新世界初始玩家落点；纯 server 有界查找，依赖原世界 getVoxel。保持 seed/generatorVersion 基础地形不变，不平整世界、不清空体素、不重定位已保存玩家、不改移动碰撞规则。自然营地和生物以此点为中心由 Change9 初始化。

## 关键决策

从原点按固定同心格点顺序找候选，优先草/土/石/沙/雪地面，排除水/树冠/树干/人工光源；检查两格头部空间为空。扫描高度有显式上限和失败返回。优先原点附近，最大水平范围64格；没有安全点明确失败，不能假装已有安全地面。玩家相机为地面上1.6米，X/Z使用格中心避免恰落接缝。

## 行为

- Given 高山超过34，When 新建世界，Then 玩家在地表上方而不嵌入地面。
- Given 原点在水面或树冠，When 选出生，Then 找邻近干燥可站立位置。
- Given 固定seed，When 重复选择，Then 结果相同。
- Given 旧世界有保存坐标，When 继续，Then 维持其原位置。
- Given 有界区域没有可站立地面，Then 返回明确不可用状态。
