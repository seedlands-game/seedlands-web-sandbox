# 死亡后的输入与复活恢复

## 背景与目标

60分钟稳定性在44分钟附近停止记录，仍等待UI操作。代码复核发现死亡只显示覆盖层，没有释放Pointer Lock；既有死亡用例先打开调试台，掩盖了真实游玩死亡时鼠标仍被捕获的问题。

## 范围与明确不做

死亡状态首次投影时关闭背包并释放鼠标与已按住移动键，让复活按钮实际可点；复活后由玩家重新点击捕获，不自动抢回鼠标。不改伤害、饥饿、复活位置、掉落或存档。

## 决策

沿用BrowserGameplay的releaseInput回调与生产PlayerController.releaseInput；先发布死亡UI状态再释放，避免PointerLock事件误打开暂停。

## 行为

Given 指针锁定并正在移动，When 权威伤害导致死亡，Then 指针释放、旧移动键清空、只显示死亡覆盖层，复活GUI可用。Given 背包打开，When 死亡，Then 背包关闭，不遮住复活。复活后可重新捕获并正常移动。

## 测试设计

`e2e/death-input-recovery.spec.ts` 先RED：真实PointerLock+W按住，Harness通过生产伤害Command触发死亡而不打开调试台；断言指针释放/复活/无自动移动/重新行走。第二次在背包中死亡验证覆盖层独占。
