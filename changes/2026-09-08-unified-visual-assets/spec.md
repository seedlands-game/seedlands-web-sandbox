# 统一视觉资产系统

状态：Active。类型：Breaking（新二进制资产存储、纹理编译与共享表现）。

## 授权与目标

用户已阅读本任务上一条完整方案并明确「OK 按这个方案推进实现」。该直接授权覆盖本合同实施，不重复索取 hash；未授权自动合并。三小时窗口从 2026-09-07 18:53 UTC 起算；约两小时冻结功能，余时验收。额度以上次实测账户周用量 17% 为起点，新增约 10 个百分点为包含缓冲的控制上限，其中约 3 点保留验证返工；仍受此前整体上限约束，账户共享与取整导致归因不精确。

## Scope

- 统一展示当前地形方块/面、物品及掉落表现、人物/生物、第一人称手臂、贴图和材质；目录覆盖测试防止遗漏。按适配器说明编辑、预览和运行用途。
- 保留像素挤出链仅用于已有适配的手持工具；普通方块维持 Chunk Mesh，实体表现不取得规则或碰撞权威。
- pixel16 默认风格：基础 tile 16×16，角色展开贴图允许更大，旧 32/64 草稿保留。独立源贴图与稳定 ID 为真相；图集和索引可重建。地形保留纹理数组。
- 编辑器可编辑独立源贴图，导出确定性图集 PNG 与索引；至少一个方块贴图真实应用及恢复默认。
- 导入自包含静态 GLB，独立有界二进制存储，保存后刷新可预览、导出及删除。拒绝外部资源 URI 和不支持的动画/skin；不创建玩法对象。
- 方块风格人物与手臂共享定义，修正比例；模型、贴图与材质进入同一目录。

## 非目标

不实现通用建模器、骨骼动画、服务器、完整模组装配、任意模型替换全类型玩法对象或变更物理碰撞。GLB 不被强制转换成像素风；默认风格不限制未来适配器。

## Decisions

源资产、材质描述、模型和用途分离。内容 revision、schema、编译器版本分别记录。导入内容先验证再写入；新本地 GLB 库不改世界存档或旧像素库。局部纹理试用存纯源快照，草稿编辑不隐式影响游戏；启用/恢复显式操作，启动读取失败须有反馈。地形逻辑 FaceMaterial ID 不改变，不将编译布局作为公共 ID。

## Behaviour / Test Design

1. Given 内置注册，When 列出目录，Then 所有可见方块面、物品、角色和手臂都有记录与预览；通过注册对照测试和浏览器逐类预览验证。
2. Given 相同纹理集合，When 编译两次或输入重排，Then 映射和像素一致；缺引用、重复 ID、尺寸/透明规则不符明确失败。
3. Given 16×16 泥土贴图副本，When 编辑并显式应用，Then 游戏地形读取该快照；刷新保持，恢复默认后清除覆盖；测试真实渲染资源像素与截图。
4. Given 合法 GLB，When 导入保存刷新，Then 模型预览仍可用且可导出；非法外链、超限、动画/skin 不写入，切换/删除/退出释放 GPU 与 URL。
5. Given 默认人物及手臂，When 工坊预览和游戏显示，Then 使用同一构件定义与材质；保留现有数学动作，游戏内截图检视比例。
6. Given 旧像素草稿与已存世界，When 升级，Then 数据不被重写或降分辨率；原工具编辑与游戏路径回归。

## RED 观察预期

实施前目录只含 10 个物品、19 个资产；没有地形/角色/手臂记录、没有 GLB 导入入口。地形通过 3×3 大图位置裁切并镜像，模型材质为运行时 24×24；以上不能通过目标浏览器旅程。新增确定性用例先运行取得 RED。
