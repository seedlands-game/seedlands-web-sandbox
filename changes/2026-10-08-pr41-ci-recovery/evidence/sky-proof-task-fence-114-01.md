# Sky 派生证明任务边界与 CI410 回归隔离

2026-10-10，远端 `d117f1ff` 的 CI410 五项非浏览器检查通过，Chromium 主旅程出现早期路线及 PointerLock 超时，视觉用例两次在原 20 秒光照就绪断言失败，原生矿车用例通过。该结果没有关闭整个 PR，亦不证明先前 V2 超时已经修复。

两个有界原用例对照保留全部原断言、时限、低画质、真实输入和 SwiftShader 条件：Sky 接入前 `1398ea2a` 的原视觉用例通过（2.9 分钟）；私有诊断 `0a501637` 仅令 Sky 证明返回 unknown，保留请求、资源及失效路径，原视觉用例通过（2.1 分钟）。后者同时跳过证明、构建、发布，不能单独定位 CPU 或 GPU 原因，且没有采用或推送这个诊断实现。原生关闭背包的旧失败及随后同产物复跑通过均保留，原因仍未证明。

实际旧生产实现的新增反例为 5 失败、7 通过：合法最大列范围在同一任务读取 524,288 个体素；epoch、世界版本、驻留、注册释放在调度机会发生变化后仍发布。修复将既有证明遍历拆成最多八列一组，生产使用 MessageChannel 交回浏览器任务队列，每组上限为 4,096 次体素读取。每次恢复及最终发布均核对同一注册、epoch、世界提交版本与完整驻留版本印记；失效返回 unknown，不发布部分证明，不缩短世界列范围，不将未加载体素推为空气。旧同步纯函数 API 保留相同语义。

本组有界验证：四个相关 Web 文件 38 例通过，包括真实 MessageChannel 下完整末列石头、空气、水吸收数据，以及后续任务未知体素使整份证明失效。测试没有修改原浏览器断言或时限。类型、静态及产物/原浏览器验证另按实际运行结果补记；单元测试与任务工作量上限不能替代可玩验收，也不能换算为帧率、延迟或 GPU 性能收益。
