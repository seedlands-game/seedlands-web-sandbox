# 独立复核

请求模型：Sol/xhigh；角色：只读风险复核。结论：通过，无当前阻断问题。复核对象为本 change 的主干集成及 Node 持久化修复；父级负责最终验证与 PR 读回。

发现并闭环：

- 按需加载仍须在启动期校验 Chunk 引用 bytes 上限；已恢复元数据门禁并补负例，不读取全部 Chunk 内容。
- GC 的 blobs/manifests 子目录本身可能是符号链接；已在枚举前 lstat 拒绝，负例证明目录外文件不被删除。
- close 必须拒绝新 ensure 并等在途读取结束后释放写者锁；已补生命周期保护与测试。

最终复读确认 CURRENT/PREVIOUS 可达集、不可变文件与 durable 指针顺序、首次 Chunk 加载的 bytes/hash/身份/版本校验、损坏拒绝及旧读取不覆盖新缓存。GC 删除或 fsync 失败沿用既有提交后失败语义：调用可能失败而 CURRENT 已 durable，重启以磁盘读回为准。

资产树独立比对为 30/30 个 blob hash 一致；新增集成旅程覆盖工坊保存/应用/刷新、游戏启动和图标、公开 GLB 及导入后刷新。

专用存储目录仍采用协作写者锁；未验证恶意并发进程在 lstat/unlink 之间替换整个子目录的情形，本次不声称提供 dirfd/openat 级敌对文件系统隔离。
