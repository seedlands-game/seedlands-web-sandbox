# 试用资产工坊

1. 在仓库执行 `pnpm dev`，打开输出的本地地址并加上 `/asset-workbench.html`。
2. 左侧“按物品”选择石镐；看像素源、真实 3D、图标/贴图关联；切灯笼、泥土块等查看不同模型适配。
3. 点击“复制为草稿”，选择颜色，在画布绘制。撤销/重做、厚度、握持点和关联贴图可编辑。
4. 右侧切“第一人称手持”，尝试挥动、连续采集和停止收手；预览使用游戏同一代码。
5. “保存修改”后刷新，从“按资产”查找草稿；导出资产包，再导入会创建独立副本。
6. 新建支持16/32/64画布；PNG和其他程序化模型当前仅支持查看。700像素宽窗口通过顶部“资产库/编辑/预览”切换面板。

保存只在此浏览器，不会覆盖游戏内置物品；备份使用导出。当前木斧、石镐的游戏图标已同源化。若要在游戏观察，可运行既有游戏并通过正式 debug give 命令取得工具，或执行以下当前需求用例：

```sh
pnpm exec playwright test changes/2026-09-07-asset-workbench/e2e
```

明确边界：工坊管理多类型资产；像素挤出适配的游戏绑定仍限不可放置的木斧/石镐，方块与实体不走此生产管线。没有云服务、艺术3D编辑或自动发布草稿。
