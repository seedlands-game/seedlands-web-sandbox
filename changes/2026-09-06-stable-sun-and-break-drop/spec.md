# 稳定主光影与破坏掉落过程

## 背景与目标

用户在已交付 MVP 中反馈：树下主光影仍随时间或视角闪烁；破坏方块形成掉落物并落地时有卡顿。基准生产版本为 2257aff，交付记录至 e684516，已按用户要求推送并创建 GitHub PR #7 指向 main。

本 change 使用真实连续输入和连续帧定位，不把静态截图、平均 FPS 或局部灯更新计数视为主光影稳定和掉落流畅的证明。完成态是同画质下稳定的太阳阴影，以及有分段证据支持的破坏到落地过程优化。

## 范围与非目标

范围：太阳阴影相机/采样/方向与辅助相机的关系；方块破坏事务、remesh 上传、掉落呈现和落地路径的有界性能修复；定向可观测性与需求测试。保留现有世界、材质、阴影、反射、3D 掉落和统一物理模型。

不做：降低既定画质或取消太阳阴影来掩盖问题；再一次重写物理或存档；修改地形版本；引入新通用引擎；改写历史 Delivered 用例或扩大长期 E2E 基线。

## 决策

先复现再选择最小修复。按跨模块渲染问题记录 Breaking 范围；用户已持续授权自主推进 SDD 和修复，无需重复等待许可。根因、具体生产取舍和合同 hash 在实施前补充，并由独立 Sol 复核；未知性能瓶颈不提前写成已确认事实。

Astra 负责太阳阴影，Sol 负责掉落阶段的分段定位和实现。共享工作树按文件协调，浏览器/性能窗口串行，结果汇入同一分支。已发布 PR 当前快照保留；新改动完成验证后本地提交，再按本轮 push/PR 授权更新同一 PR。

## 行为

- Given Medium/High 的天然森林和受控遮挡场景，When 相机静止、缓慢旋转、平移及昼夜正常推进，Then 阴影跟随真实世界光源连续变化，静止时间下没有周期性亮暗翻转；正常时间推进没有明显边界闪跳。辅助反射相机更新不得改变主视角阴影。
- Given 改动真实遮挡物或移动实体，When 可见几何改变，Then 阴影及时响应，不能用永远冻结的贴图伪装稳定。
- Given 按住左键破坏多个方块，When 正式事务生成掉落物并经统一物理落地/吸附，Then 物品数和位置正确、无重复创建/拾取，阶段耗时可区分；同机同场景优化后不出现由该路径引起的长主线程停顿。
- Given 既有水面、视角模型、保存和世界切换，When 新逻辑生效或销毁，Then 不新增错层、残留资源或静默数据丢失。

## 实施前根因与具体决策

2026-09-06 只读源码与基准显示：冻结时间的树冠场景 12 帧地面 ROI 完全相同；正常时间时太阳方向直接使用 20Hz 世界时间阶跃。PlayCanvas 2.21.4 的单级方向阴影覆盖 58m，在 Medium 512 图上包围球 texel snap 量级约 0.71m；太阳基向量变化也会触发跨格。树叶自定义 opacity 在已有 ADDRESS_REPEAT 的纹理坐标上先 fract，再隐式取样，会在重复边界破坏 LOD 导数，作为待独立 A/B 的放大因素。禁止将这三个候选未经逐项对照就统称已解决。

太阳实施选项限定：保留 512/1024 分辨率、58m 距离和 REALTIME，用 PlayCanvas 公开级联数量/分布/混合参数细化近场；重复纹理使用原始 UV 及原有 repeat sampler，以连续导数采样；仅表现层可按帧对收到的世界时刻做有界连续插值，暂停、显式设时和世界切换立即重置，不改权威时钟、昼夜倍率或物理。每项按单独反例/连续帧对照决定是否保留。最小确定性测试记录于 `tests/app/sun-shadow-stability.test.ts`。

掉落首轮真实采集两块并落地未出现超过既定 20ms p95 / 33.34ms 最大帧间隔的长帧，不能将此判为用户体验已解决。源码显示实际实体 presenter 每渲染帧调用，但 dt 来自约 20Hz 的 gameplayTime：中间渲染帧 dt=0，位置保持后阶跃。正式反例 `tests/app/gameplay-entity-presenter.test.ts` 读取真实 PlayCanvas 节点；应验证静态权威目标在连续表现帧仍被平滑追随、落地不穿地、删除当帧移除。

掉落实施边界：主线程用独立帧 dt 推进表现，权威快照只提供目标/事件时间；快照回调不重复推进表现时间。保留有界位置修正和大位移重置、暂停/重启/销毁清理及同帧拾取移除，不改变实际实体位置/速度或物理规则。若分段成本显示真正长帧，再依据同次证据增加有界创建/复用，不能预先堆缓存。

## 太阳连续帧诊断记录（进行中）

基准受控场景包含草地与八棵树，固定相机与 14.93h 时刻。先检查默认 READ framebuffer、非黑画面和 GL 错误，再记录地面宽 ROI 的连续 240 帧绿色通道差。一次读取了后处理 framebuffer 的 GL1282 全黑记录，以及一轮全部位于单色阴影内部的小 ROI，均已判无效，不用于通过证明。该 GPU readback 仅诊断视觉连续性，不用于 FPS 或性能结论。

Medium 基准的逐帧通道差 p95/max 为 0.3427/0.9246；仅表现时钟为 0.2772/0.6396；仅三级级联为 0.2641/0.4352。组合候选首次采样前预置 p95<0.25、max<0.6、超过90%帧的实际太阳表现时刻前进；组合复核为 0.1680/0.4268。暂停后的渲染提交完成再采 36 帧，最大差为0。第一次暂停采样混入了设时前最后一帧，不能当作暂停态闪烁；已在采样前等待实际渲染帧交接。原始日志分别位于 `/tmp/seedlands-sun-wide-baseline.jsonlog`、`/tmp/seedlands-sun-clock-only.jsonlog`、`/tmp/seedlands-sun-cascades-only.jsonlog`、`/tmp/seedlands-sun-combined-2.jsonlog`。

High 组合候选同门槛仍 RED，p95约4.56；暂停态差为0。去除重复 UV 的 fract 单因素没有解决 High（p95约4.36），加大 bias/normalOffset 也没有解决（约4.41）；这两项诊断改动只在临时副本，未纳入生产。继续定位，不能把数学可疑点冒充实际根因。

独立 Sol 发现100倍速下150ms合法延迟快照可能超过0.5h，原候选以delta猜测显式跳时会误重置。正式新增高倍速、午夜和长帧用例 RED 后，移除该猜测：显式设置只由 reset 处理，运行态始终连续追随；阶段标签也统一读取表现时刻。当前太阳定向 Vitest 5/5 GREEN。

High 原版同场景p95为0.488，说明直接把Medium的三级分布照搬到1024会引入更细叶孔的二值阴影采样噪声，不能把较细纹理等同更稳定质量。保持三级及总纹理分辨率，High第一段覆盖约14.7m、Medium约7.2m，让近段具有相近世界采样尺度，High额外预算用于中远距离；单因素High分布0.25已使p95/max降到0.2679/0.6606。独立PCF5对照仅降到3.54，不能单独解决。下一候选合并High宽近段与PCF5过滤；Medium保留PCF3。PCF5增加每次阴影采样的过滤成本，必须以无readback的同机天然森林帧成本验收，不能用截图采样时的FPS替代。新增近段尺度比例单元反例先RED；仅最终达标选项进入生产。

High宽近级+PCF5组合仍RED（p95 0.284，max 0.762），且readback诊断帧间隔p95由19.4ms增到22.4ms；这不是正式帧成本证明，却说明不能仅扩大过滤核。丢弃PCF5，继续在已定义的级联分配边界内采用High分布0.15（第一段约16.56m、近级世界尺度约为Medium的1.16倍，仍远细于原58m单级），保留PCF3。正式尺度比例门槛仍0.9..1.2；视觉门槛和天然帧成本门槛保持不变。该有界参数调整属于同一采样分配方案，最终hash重新独立复核。

## 最终生产决策

采用50ms时间常数的表现时钟，按真实渲染步长连续追随权威时刻；不改变权威游戏时钟、物理频率和存档。显式设时、恢复与暂停独立重置；运行态不按延迟快照幅度推断跳时。

太阳使用三段级联，Medium为512纹理、分布0.65、PCF3；High为1024纹理、分布0.25、PCF5。距离58m、边界混合0.15、REALTIME更新和原bias保持。High近段覆盖约14.66m、Medium约7.12m，近级世界采样尺度相近；High过滤为公开5×5核/9次比较采样，成本由天然场景独立帧成本门禁约束。材质纹理与反射算法不改。
