## 三、关键决策

### 统一美术与听觉方向

保留已确定方向：**风格化奇幻、清晰体素、轻手绘质感、古老奥术文明**。自然世界保持明亮和可探索，深色主要承载 UI 层级。

| 语义         | 视觉                                         | 动态与声音                                                        |
| ------------ | -------------------------------------------- | ----------------------------------------------------------------- |
| 结构与可靠性 | 黑曜石/深石面板，局部黄铜边框，安静的信息区  | 短而明确的反馈，柔和金属/合成确认音                               |
| 正文与说明   | 暖中性色、局部羊皮纸材质，可读的中英文与数字 | 稳定显示，不用装饰动画干扰阅读                                    |
| 发现与奥术   | 稀疏青/紫、晶体与符文                        | 柔和显现、FM/玻璃音色；不暗示已有魔法玩法                         |
| 伤害与危险   | 与黄铜区分的红橙色，短时边缘反馈             | 短冲击与低频瞬态；可关闭震动/降低动态                             |
| 世界音乐     | Sparse Electronic Fantasy Ambient            | 低音符密度、弱节拍、长留白、温暖 Pad、柔和 Bell/Pluck；随环境缓变 |

素材优先：世界纹理、UI 框、槽位、图标应放回真实画面后检查。不会以概念图中城堡/高山密度作为当前生成器的逐像素验收要求；也不会只改 CSS 颜色便宣称风格完成。

### 保留的技术边界

1. GameServer 持有世界、实体、时间、背包、伤害、需求、行为和动作真相。渲染、音频与 UI 消费快照及语义事件。
2. 世界编辑继续经正式事务/World 编辑路径。稳定数值 Voxel 与字符串 Item namespace 不混用；seed + generatorVersion 决定的基础地形不因表现设置改变。
3. 新内容放置优先作为有版本的世界初始化/内容层，通过权威编辑落地。需要更改生成或存档合同必须先写迁移、旧存档与确定性用例，不能悄悄重解释旧世界。
4. GameServer 是逻辑权威，不假设它已独占某个 Worker。是否移动计算取决于实际 trace、快照成本和 A/B。
5. NPC 感知带 observer identity；Action 有 id、完成/失败/中断结果。未来高层决策来源可以替换，底层移动/碰撞/攻击/进食不重写。
6. 一个 Svelte root；UiBridge 按分片、变化和不同频率投影。动画可插值显示值，但不能另存权威生命/背包。
7. GlobalAudio 管主音量、菜单声音；WorldAudio 跟随 WorldSession。语义事件、低频环境上下文、少量高频空间姿态分通道，不每帧扫描整个世界。
8. 沿用 Web Audio + PlayCanvas Sound + Tone.js 的职责方向。先跑通空间/SFX 和 Cue/Fade，再扩充节拍与 Stem；同一 AudioContext 的适配能力在子 change 先验证。拒绝把分层音量 UI 当作完整音频实现。
9. 暂停建议冻结当前本地权威模拟，音频执行淡出/暂停策略；背包与暂停的具体时间语义写进子合同。UI 暂停和世界暂停是不同接口，为未来常驻服务保留边界。
10. 优化实验与新增功能分开取证。优化项无可信收益可放弃；视觉必达项不能因实现困难悄悄降为可选，只能改变实现方法或报告未完成。

### 自主交付约定

用户在本次对话明确允许本次整体任务自主推进 SDD、无需逐项人工批准，并于 2026-09-05 明确要求创建 goal 开始执行。这一授权覆盖本地子 change 的 spec 修订、实现、测试、修复、集成和提交，不再逐个索取 spec hash 批准。

仍保留 spec-first、RED → GREEN、实质变更记录、证据绑定源码版本以及准出门禁；取消的是逐项等待人工审核，不是取消工程约束。不为此修改仓库的全局 AGENTS 规则。

普通实现取舍、预算内画质降级、素材迭代、合并冲突由实施者处理。改变目标设备、删除必达体验、扩大到 Agent/联机/魔法、不可恢复地覆盖用户存档等属于目标/高影响边界，需显式重新对齐。长期 E2E 提炼仍遵守仓库独立评审规则。

## 四、行为与完整体验

### 黄金旅程

1. 给定无存档的新用户，打开游戏后能辨认“新建世界”和设置，输入 seed 并进入真实加载阶段；不需要控制台。
2. 初次进入安全且可行动的位置，以克制的提示学会观察、移动、采集、拾取、打开背包和合成。
3. 获取木石与食物，制作斧/镐，明确感知效率提升，建一个小据点并布置可用照明。
4. 穿行林地和河岸，看到/听到材质、光照、水面与环境差异；水体交互与碰撞语义一致，不把渲染水冒充完整流体。
5. 观察被动生物觅食/避险、遇到敌对生物追逐/攻击；受伤、进食、恢复、死亡/复活与掉落均来自实际规则。
6. 找到简单 NPC 营地，看见 NPC 按时间前往 POI、处理饥饿或躲避威胁。无生成式对话也成立。
7. 暂停、调整画质和音量、保存、回主菜单并继续；世界编辑、玩家与需要持久存在的实体恢复一致。

这条旅程使用真实键鼠/Pointer Lock 与 GUI。Harness 可以设置算法边界 fixture，但最终玩家闭环不得靠 `/give`、`/tp`、`/damage` 或测试专用捷径才能成立。

### 必测失败路径

- 背包满、资源不足、放置撞人/超距、失效目标：解释失败且不丢物、不重复掉落。
- 采集中暂停、失焦、开背包、死亡或离开世界：动作按合同停止，关闭面板后没有残留输入。
- 世界编辑阻断 NPC 路径、跨 Chunk、目标不可达/已消失：有界重算，产生失败或中断，不穿墙、不无限搜索。
- 保存/加载失败：显示真实结果、可重试，不显示虚假的成功；正常保存恢复不能复制物品或覆盖其他 seed。
- 切换世界或反复进出：旧 UI 事件、声音、实体、Worker 请求和 GPU 资源不流入新会话。
- 音频尚未解锁、静音、切后台/恢复、缺少外部参考音乐：游戏仍可进入，不能爆发积压音效。
- Low 关闭反射/后处理后仍能判断资源、目标、危险和可走区域；reduced-motion 不丢失状态信息。

## 五、测试设计

为每个子 change 先建立可执行用例并取得对应 RED；无法自动化的听觉/视觉语义先定义可观察预期。纯合并使用既有基线 GREEN 验证，不制造人为失败来伪装新增行为 RED。

- **Vitest**：规则原子性、实体/动作状态机、观察范围与 LOS、导航/失效重算、世界内容确定性、存档迁移、音频 Cue 选择/预算/生命周期、UI 投影与边界。涉及 `src/world` 保持行覆盖率至少 80%。
- **Playwright-change**：各子 change 的真实输入、DOM/状态、启动/存档/会话、画质设置、实体呈现、音频解锁/释放和总黄金旅程。父 change 的最终总体验收用例放在本目录 `e2e/`。
- **Playwright-baseline**：集成后复跑当前 `tests/e2e/`，不自动把所有历史 change 加入默认 runner；必要的历史预期在新 change 重新定义。
- **Midscene**：父 change 的 `midscene/` 覆盖主菜单、HUD、背包、合成、设置、日/夕/夜、林地/河岸/营地、危险反馈和 reduced-motion 的可见语义。
- **音频专门证据**：自动验证调度、总线、静音、声源数量、合成输出峰值/非静音与资源释放；浏览器录音及实际试听验证音色、留白、听觉层级与接缝。Midscene 不证明“好听”，音频数值也不代替试听。试听明确记录为 Manual supplement；未试听不得将听觉体验标为通过。
- **性能**：同机同 seed 同路线、同分辨率和实际 DPR、同负载、预热、前后台状态固定；记录 source SHA、运行 id、浏览器/引擎版本。优化候选做 A/A 噪声和配对 A/B，新增视觉功能另列成本。
- **稳定性**：60 分钟混合探索/战斗/建造；10 次世界进入/离开；重复跨区往返。检查活动实体、声源、监听器、待处理请求、Chunk 与 GPU 资源在稳定区间内回收，不要求 GC 堆字节精确回到起点。
- **设备**：主设备真实可见浏览器游玩与性能采样，headless 作为自动化证据；未取得实际设备数据不能声称该设备通过。

### 性能目标建议，需在设备与基线确定后冻结

- 主平台建议：当前 Mac、桌面 Chrome、1920×1080 viewport，并明确实际 render scale/DPR；Medium 以接近稳定 60 FPS 为目标。
- 建议稳定混合场景门槛：帧间隔 p95 ≤ 22 ms、p99 ≤ 50 ms；探索 streaming 单列，p95 ≤ 33.3 ms；用户输入到首个可见反馈 p95 ≤ 100 ms。工具采集完成时长不计为输入延迟。
- 这些是待验证的**同机验收候选值**，不是已测结果，也不写入跨机器 benchmark 硬阈值。实现前先测集成基线；不达预期时显式讨论/记录预算取舍，不能验收失败后悄悄放宽。
- High 记录视觉收益与成本，不强制所有高级效果同时 60 FPS。Low 必须实测比高档降低相应 GPU/CPU/资源压力，不能只是切换标签。
- 实体取样建议 10/100/500，1000 作为探索压力档；正常同屏/激活上限由基线确定，不承诺千实体全部完整模拟。AI、导航、感知分别计时，避免全部 60 Hz 和全世界扫描。
- 保留 UI 已有 4 Hz debug、最多 20 Hz 采集进度及变化驱动投影；音频活跃声源、解码缓存、阴影光源、反射分辨率/更新频率必须有显式上限。
- GPU duration 或其他计数不可取得时写 `NOT_COLLECTED`/`UNSUPPORTED`。首屏、初次进世界与再次继续的耗时分别报告，不混成一个加载数字。
