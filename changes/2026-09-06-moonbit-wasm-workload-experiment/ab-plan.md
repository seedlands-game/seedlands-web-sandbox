# 当前评测合同：Rust-first 浏览器 Wasm

当前只验收浏览器 Integrated Server。Node Dedicated Server、worker pool和Node-API不实现、不计入本次成本；多目标草案保存在`future-multi-target-matrix.md`，仅为未来参考。全部浏览器headless，不反复打开窗口。

## 变量分层与矩阵

| 变体                      | 用途与固定条件                                                                        |
| ------------------------- | ------------------------------------------------------------------------------------- |
| TS单线程kernel参照        | 同算法/布局在无渲染kernel页主线程运行，隔离搬线程成本；不重写整个五Worker产品为单线程 |
| TS Web Worker             | 原版TS与同布局TS分别报告，是语言增量的控制组                                          |
| MoonBit Wasm + Web Worker | 只测已完成实现，不新增服务端Moon算法                                                  |
| Rust Wasm + Web Worker    | 同core/ABI/数值输入、同pool大小，包含准备、传输和返回转换                             |
| A / A′ / B统一            | 冻结原TS / 新适配全关 / 本环境通过项集合；真实游戏默认五Worker                        |

先固定pool=1比语言与布局；再对通过项固定工作总量比较1/2/4 Worker扩展，可用核不足明确N/A。真实游戏额外General Worker另作拓扑分层，不能与语言变更混合。原生host小型benchmark只诊断同core计算上限，不作当前产品采用依据。

不能把TS列预计算、移除渲染竞争、算法重排或更多线程归因于Rust。W02宏观地形仍TS，准备成本必须计入端到端；W04/W05是一体描述符两类场景；W14/W15独立与共驻分开，不重复计功。

## 预注册稀疏单元

不扫描全笛卡尔积。首阶段三共享形态为W02/W07/W14，W15只作共驻依赖与独立microprobe；W03/W04-W05/W06是已有浏览器候选。每族先固定一个生产代表批量、自然/压力两类分层语料，四浏览器变体只改变一个因素。极端正确性case不等权混入自然性能集。

只有初筛通过的backend再加小/中/大三档批量和1/2/4池大小；未过新增复制/维护门槛直接给拒绝理由。所有13候选仍有追踪行，W01/W08/W11/W16等成本筛除项写清原因，不为“测齐”无限重写。

正式采样前生成matrix manifest，冻结场景、主指标、seed/version、算法/布局、批量、并发、corpus/runner/source/binary hash和排除条件。探索样本不用作确认样本。多候选显著性采用独立确认集或Holm校正，最终还有独立统一AB，避免挑选偶然好结果。

## 正确性与样本

先逐字节/字段等价，再计时：数组顺序/float bits/水面AO/存档/候选与read-set/有序写入/输入不变。每run确认真正请求的backend ready、无trap/fallback和产物身份。摘要只用于轻量采样，不能代替强等价。

corpus schema2覆盖generator2/3、负坐标/编辑、W07的4/5Chunk（约465KB输入）、128frontier+64cleanup/跨边界真实写入，codec的稀疏/密集/零差异/fluid sidecar。旧schema1短测保留诊断，不混入正式数据。

- 每主场景先6对A/A校准；现有P0是6场景各1对，仅作探索性噪声证据。
- 正式10配对完整运行，顺序平衡；每run预热至少5秒或20任务中较长者。性能窗口串行，无并行编译/测试。
- 每正式run延迟分布至少1000任务；昂贵任务必须预注册测量时长和不足原因，不能用30样本的插值假称可靠p99。真实产品自然输入30秒，30次流体可见事件仅给run内p95，统计单位仍是完整run。
- 10,000次paired bootstrap给95%CI，固定随机种子；帧/任务不是独立实验。记录全部失败/未知指标，不选择性删样本。冷启动另做10对，新进程/context并声明HTTP/OS缓存状态。
- Chrome版本、CPU、CSS1920×1080、Medium、DPR1、内部1689×950、可见/焦点状态、后台线程数固定并记录；全部headless，不声明headed真实FPS。

## 必录指标

| 指标        | 口径                                                                                                                  |
| ----------- | --------------------------------------------------------------------------------------------------------------------- |
| 核心计算    | core开始至返回，已准备输入；小核用等量批次、报告非隔离时钟精度                                                        |
| JS/Wasm边界 | adapter入口、marshal完成、core开始/结束、unmarshal完成；no-op批量标定固定成本。扣减残差只叫估算                       |
| 完整任务    | 输入准备起，包含clone/transfer/排队/计算/输出回传/宿主转换，结束于消费者可用                                          |
| 复制与增长  | 双向bytes、次数、scratch/分配峰值、memory.grow次数和耗时；首次增长与稳定复用分开                                      |
| 延迟/吞吐   | p50/p95/p99及tasks/s，同总量完工时间；样本不足不做p99采用结论                                                         |
| 并发效率    | S(N)=T(1)/T(N)，E(N)=S(N)/N，记录实际线程/核心，禁止隐藏嵌套并行                                                      |
| RSS/GC      | 独立Chrome进程树RSS、CDP heap/GC可观察项、每Wasm线性内存；linear memory不冒充总RSS，未支持填UNSUPPORTED/NOT_COLLECTED |
| 启动/包体   | Worker启动、下载、compile/instantiate、首次调用、raw/gzip/glue、构建耗时与工具chain hash                              |
| 产品        | ready、跨Chunk、编辑/流体至真实可见、保存、activeCPU、帧/physics尾延迟和内存                                          |
| 确定性/维护 | 结果/错误语义、随机顺序/重复运行、两语言规则同步与构建维护人日；未来未实现消费者不记已获收益                          |

## 采用与止损

成本初筛：预计省时>新增边界成本2倍，且每任务≥0.2ms或持续≥1msCPU/秒；启动/地图≥20ms。超出普通移植3工程日、完整物理5日的候选先停止扩项并说明，Rust共享价值可重新提出有界方案但不能自动取消预算。

正式分项：相对当前产品TS端到端p50改善≥15%、配对95%CI下界>0；同布局TS仍有可辨语言增量。若布局有效而语言无收益，就保留TS布局优化。p95/p99不得超噪声及预注册容差；小批量负收益以实测交叉点回退，不强制全量Rust化。

统一A/A′/B：至少一个预注册主要产品指标改善≥10%、95%CI下界>0。frame p95/p99容差max(0.5ms,5%)，physics max(0.1ms,5%)，交互/任务max(2ms,5%)；看到结果后不能换主要指标。整体不过则消融，不启用负收益组合。

内存单实例≤32MiB、默认五Worker总linear≤96MiB；新增gzip Wasm/glue≤150KiB，额外冷启动≤max(50ms,原值5%)，稳态60秒可摊销。压力池单列预算，不混产品内存账。

MoonBit额外保留门槛与12个月维护账本见spec；共享计算默认Rust，原投入不成为继续投入理由。正式支持仅以当前可运行的浏览器/机器证据声明，其他设备兼容性标待验证；未来Node/NAPI成本不摊入本次已交付收益。
