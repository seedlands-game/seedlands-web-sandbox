# NPC 持续行为与持久认知

2026-09-09 用户试玩后确认的新决策。当前处于[实施中](../changes/2026-09-09-npc-behavior-workspace/spec.md)，以下是目标合同，不是已完成的体验声明；替代单目标MVP中相冲突的回路、内存会话和供应商耦合设计。

## 世界行为

每个角色只有一棵生效的有状态行为树。树表达职业、补给、休息、跟随与危险取舍；不存在强制自保或日程的第二个 owner。世界引擎继续约束物理、权限、物品和执行预算。技能在 RUNNING 时跨 tick 保持身份，支持失败、取消、清理和有界重规划；模型调用结束不代表目标完成。

模型提交目标和树的原子更新；稳定节点ID用于迁移兼容活动，旧身份/旧树版本或非法候选保留原树。通用行为树执行器优先复用，Mistreevous需通过实例隔离、注入时钟/随机、抢占与重建恢复准入。世界仍由Authority唯一写入，Headless/Browser共享合同。

## 认知与记忆

树中的非阻塞RequestRejudge和宿主时间兜底独立。新逻辑认知回合刷新兜底时刻；工具修正、传输重试与Pro压缩不刷新。每角色最多一个事务，忙碌合并事件，世界身体继续生活。

每角色以可信world/timeline/actor/incarnation绑定PG虚拟工作区：AGENT.md受保护规则与配置插槽，SOUL.md只读人格起点，MEMORY.md仅授权Pro流程发布。完整旧窗口只供系统审计，不给角色检索，以保留遗忘语义。初始背景、亲历事实和推测分别记录；SOUL固定不限制未来立场变化。

LangChain标准Agent/messages/tools与LangGraph saver/store承担通用流程。稳定前缀与追加窗口从首条消息持久化；世界received、窗口included与compacted游标分开。每轮环境含完整生效树与运行状态、局部观察和真实过程日志。默认128K总窗口/112K软阈，MEMORY双上限4000估计tokens与16KiB。Pro失败保留旧窗口，硬阈暂停认知，不用规则摘要或Flash绕过权限；身体仍继续。

## 模型与交付顺序

认知只选择flash/pro逻辑档位。LiteLLM Proxy是本地Docker首选，供应商、密钥、共享排队/配额/重试全部在网关内闭环；Agent不另建供应池。全局与部署并发必须分别验证，三个实例不等于三个独立额度。具体发布版本和配置以准入证据冻结，边缘部署延后。

按A固定树长期生活（至少三个模拟昼夜、显式认知触发与短浏览器目标验收；真实长时间仅按时间相关风险选用）→B单Agent持久认知/真实策略效果→C三个独立Agent与共享模型池推进。随后接可追溯随机出生包Factory。多租户账号、云部署/扩容、LOD、离线追赶与World AI不在本期。

细节示例、失败条件和实际阶段状态见当前change，不用通过一次工具调用或工程门禁宣称活人感已经成立。

## 请求和恢复的实施边界

标准 Agent 每个逻辑回合最多 8 个模型步骤、3 次行为候选；网关传输重试不计作新逻辑回合。每次工具结果先写入 PG journal，再继续下一个模型步骤。中断造成未知工具结果时，恢复记录显式的 host-recovery / outcome unknown，不伪造执行成功或失败，也不盲目重放世界效果。

当前上下文计数采用 UTF-8 字节的保守 token 上界，加消息封装和 8192 输出余量。128000 总预算 /112000 软阈是配置合同，不把字符、字节或供应商准确 token 数混称；后续接入可靠 tokenizer 后可提高窗口利用率。压缩预检只包括活动窗口、三个当前文档、公开工具、待追加事件和观察；封存窗口不重新计入，也不可由模型找回。

应用存档用哈希清单配对世界 checkpoint 与 PG portable workspace。浏览器先暂停世界与认知、收齐最后观察，再导出两个 owner 的产物。恢复总是创建新 timeline；PG 导入未完成时，持久恢复标记阻止创建空白认知。页面重开后可连接服务并重新导入原文件完成恢复。已连接过认知的世界断线时拒绝生成不含记忆的伪完整存档。世界与 PG 不宣称分布式原子事务。

AGENT 的叙事插槽上限 6KiB，固定正文与叙事按 8KiB 预算控制；自动生成的工具 schema、树语法和 capability 目录另外计入完整文档及每次模型请求。完整 AGENT 文件上限 32KiB，避免把生成的能力目录错误挤入叙事预算而导致正常伙伴无法绑定。
