# Classic 视觉基线

2026-09-22 用户确认：Classic 保留早期 Minecraft 的方盒比例、清晰像素和简单材质；贴图适度降低饱和度、减少随机噪点、强化材质结构。Modern 的细致模型与玩法另立 Playbook，不进入本次实现。确认稿见 `reports/2026-09-22-visual-audit/classic-v3/`；概念稿用于方向判断，不作为可裁切的生产纹理。

## 生产约束

- 地形使用16×16像素图块，草、木、石分别保持自然绿、暖棕和中性灰。矿物、砖缝、年轮、功能面的结构应可辨，不能全用随机噪点换色。
- 草、花、蘑菇、树苗、甘蔗和枯灌木使用透明背景的双面交叉平面，进入Chunk Mesh。几何、选取和碰撞是不同合同：植物可选取采集但不挡人；仙人掌保持可碰撞体。
- 十二种Classic生物有独立轮廓、米制尺度、关节pivot和动画。默认GLB保留作者尺度；用户模型沿既有导入合同处理。不能用通用黑盒或整身上下移动伪装生物。
- UI采用低分辨率像素框、明确状态与选中轮廓；生命、护甲、氧气使用不同图形。
- 植物的透明配置、像素轮廓与世界尺度分别验收；启用 cutout 不代表帽盖、花瓣或草叶已可辨。普通蘑菇与红蘑菇在世界和物品视图中保留同一颜色身份，避免周期白斑形成斜纹。
- 默认后处理不额外增加材质饱和度。目录搜索保持固定视口，常规物品名称来自内容定义；内部 ID 不作为日常界面副标题。普通探索隐藏战斗待机文字，保留动作过程和结果反馈。
- 自发光表面与周围环境受光分别实现、分别验收。画质档位不得成为基础方块照明数量上限。
- 不引入PBR、WebGPU或外部商业素材。用户外观项目只迁移退役绑定，不整库重置。

## 源与验证

地形及物品源在 `apps/web/src/client/presentation/`。生物配方及重建说明在 `scripts/assets/classic-creatures/`，导出资产和hash清单位于 `apps/web/public/models/classic/`。所有Blender操作由用户指定的Astra执行。重型生产、构建、测试与浏览器操作经 `node scripts/benchmark-window.mjs -- <command>` 预约同一默认性能锁。

以资产绑定完整性、真实GLB关节帧、类型和边界测试证明静态合同；以同一生产构建中的实际场景和连续帧证明视觉结果。Blender预览不证明浏览器正确；像素数量和hash不证明美术好看。初次重建见 `changes/2026-09-22-classic-visual-rebuild/`；后续真实试玩发现的问题、修复与未验证项见 `changes/2026-09-22-classic-experience-coherence/`。
