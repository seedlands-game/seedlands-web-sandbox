# 单角色认知与持续生活

> 2026-09-09 试玩后本MVP停止继续完善；当前实施以[持续行为与持久认知](npc-behavior-and-memory.md)为准。本页保留此前阶段合同，不作为相冲突新实现的约束。

2026-09-09 决策基线。交付状态与实际证据以[当前 change](../changes/2026-09-09-living-npc-mvp/spec.md)为准。本页替代 H1/H2 设计中 Flash 高频 tick、Pro 作为决策候选或每日回顾的阶段性假设；不重写历史交付记录。

## 核心回路

Authority 内的确定性执行层持续负责感知、导航、身体、目标执行、拾取、食用、受击与撤退。模型选择可持续执行的目标；一次模型调用之后，角色可以行动数分钟。没有连接、模型超时或预算用尽时仍保持基础生活。模型不能瞬移、获得虚构物品或任意 patch 世界。

持久目标在暂时没有Action时仍拥有执行权：idle保持原地，follow到达后等待目标继续移动；普通settler的日程/游荡不能接管这些等待状态。觅食目标在没有食物时仍允许基础游走，威胁和受击反射优先。

认知宿主使用 LangGraph 显式状态图与 DeepSeek 薄协议适配器。状态装配、模型调用、工具校验、世界提交、等待回执和对账有各自边界；世界写入始终经过 Authority。选择依据是[已做的框架合同比较](../changes/2026-09-09-developer-world-harness/framework-decision.md)，并非宣称该框架运行成本优于所有候选。

Flash Vision `deepseek-v4-flash-vision-exp` 负责日常决定，本期只发送文本。玩家交谈、受击、目标失效等有意义事件可提前唤醒；时间周期只是兜底，默认180秒，可配置60–600秒。实际发起的事件调用会重置兜底窗口。事件合并、并发上限、退避和预算分别限制洪峰，不能误解为“每分钟最多调用一次”。没有变化不必强行制造一次思考。

玩家暂停世界会立即向认知连接发送暂停；暂停期间迟到的行为意图不写入Authority。已发出的记忆提案仍可完成回执对账。暂停会尝试取消正在进行的请求，但不代表供应商退还已经发生的推理费用。

Pro `deepseek-v4-pro` 只做上下文压缩。没有每日回顾，也没有自动决策升级。一次模型的高质量文本不等于 NPC 已完成动作；Authority 回执与后续事件才是事实来源。

## 上下文与记忆

上下文顺序为稳定身份/性格与工具规则、已提交的长期摘要、当前受限观察、按 cursor 有序的近期经历及完整工具往返。可感知事实与角色表达分开，玩家对话作为世界内数据，不能改变宿主权限。

默认输入窗口128K，112K软阈开始压缩；可选256K与224K软阈。窗口是上限，不是每轮填满的目标。模型支持1M不代表必须发送1M：需要同时观察任务准确性、缓存命中、延迟和每次成本。稳定前缀有助于缓存，缓存命中仍以供应商实际 usage 为准。人格不通过随机温度替代正式 profile。

压缩冻结一个已见事件 cursor；Pro 总结已发生的事实、关系、未完成目标与不确定事项，不补写世界结果。摘要经 Authority 的记忆 revision 校验提交后，才切换上下文。压缩期间新事件留在下一窗口；失败保留旧历史，硬上限使用有界确定性压缩维持运行。私有 reasoning 为供应商多轮协议保留在认知宿主中，不进入玩家界面或世界公开记忆。

认知服务重连的首份有效观察只重建历史上下文，并冻结首份观察中character.eventCursor作为完整历史上界，不自动重放旧意图或发言。此边界也覆盖断线期间尚未确认的历史事件；当前基础生活与持久目标继续执行，后续新事件照常唤醒。Authority历史按每页最多32条读取；后续页仍进入上下文，只有cursor超过冻结历史上界的事件才可唤醒，不能随着分页移动该上界。首份历史不是待执行命令队列。

### 窗口容量与费用估算

按2026-09-09[官方峰时价格](https://api-docs.deepseek.com/quick_start/pricing/)（Flash输入未缓存/缓存/输出每百万token为$0.44/$0.014/$1.32），假设一次真的发送满窗口、输出2048token，估算如下；不是实际账单或缓存命中保证。

| 实际输入量     | 无缓存  | 假设90%缓存命中 | 假设全部命中 |
| -------------- | ------- | --------------- | ------------ |
| 128,000 tokens | $0.0590 | $0.00995        | $0.00450     |
| 256,000 tokens | $0.1153 | $0.0172         | $0.00629     |

本期小样本实际输入只有数千token，不能推断128K/256K任务质量或时延。默认128K是可调的初始容量决策；保留256K给更长经历，后续用同一长经历任务比较记忆保真、目标连续性、实际命中和时延后再改默认。当前会话输入/输出/请求数还有独立预算，达到预算会明确进入基础行为，不以缓存便宜为由允许无限调用。

## 主体、数据与权限

principal 是调用主体的统一模型，NPC、玩家、脚本、API 等只是可配置角色。鉴权依据主体获授的资源、操作和目标作用域，不根据“是不是 Agent”分叉。角色控制入口与开发者世界端口共享同一世界实现，但授予能力不同。

世界只暴露角色身体、自己的背包/目标/记忆、局部可见目标引用、有来源事件以及受规则约束的语义目标。可见引用不是全局 Entity ID；目标消失或已离开感知范围需要重新观察。全局 inspect、checkpoint 管理或任意世界命令不授予外部认知连接。

观察是思考开始时的受限快照，不是锁住整个身体与感知的事务。角色revision与事件cursor拦截已被新目标、对话或后果取代的决定；单纯位置和饥饿变化不自动作废所有慢模型请求。move-to表达固定世界坐标，follow表达实体追踪：后者在Authority提交和持续执行时按entity命名空间重新验证可见性，并使用目标当前位置；同名POI不能为实体作证。前者按执行时身体位置重新寻路，地形或路径不成立会产生目标失败事件；意图接纳回执不代表路径或动作成功。发言只是角色的世界内表达，不承诺已送达离开的某个听众，也不是动作完成证明。后续若增加攻击、交易等有目标前置条件的工具，应在Authority明确校验其条件，而非让每次500ms观察都使所有决定失效。

浏览器主动连接本机 WebSocket 服务，以临时配对码绑定 session/world/epoch/角色身份与 incarnation/policy revision；每条消息校验序列。返回只允许目标与记忆提案。世界恢复或角色身份改变后旧连接失效，需要重新绑定。API key 只从本机进程环境读取，不进入浏览器、不写进配对码。

世界玩法规则与权限继续分层：授权决定调用主体是否能申请动作；玩法规则决定这个世界中的动作是否成立。可编程事件拦截、PvP ruleset、World AI 与模拟 LOD 均留在后续独立 change。

## 验收和后续

本期必须看到一个玩家与一个持久 NPC 在浏览器相处：目标连续、真实物品变化、对玩家与危险有响应、断线能继续、存档能恢复。工程评估对目标连续性、事件响应、真实后果、人格一致性分别记录证据；少量模型样本不冒充真实用户留存或成本优胜结论。

后续先根据玩家实际体验完善动作丰富度和长期性格一致性，再分别推进模拟 LOD（精度切换、休眠、离线追赶）与 World AI（区域/聚居地/宏观事件预算）。它们复用现有角色、Action、受限观察、事件和存档合同，不把宏观全局信息泄漏给个体认知。

动作执行历史也有界：活动Action与角色尚未结算的引用持续保留，普通终态只保留最近256条。持续跟随的重规划不会无限堆积旧路径和存档记录；长期记忆依赖已提交摘要与角色事件，而非无限Action列表。
